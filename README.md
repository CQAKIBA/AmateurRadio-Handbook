現代のアマチュア無線について、運用だけでなく、技術・製作・測定・実験・研究まで扱うオープンなハンドブックを共同制作するプロジェクトです。

本プロジェクトは有志による独立した活動であり、一般社団法人日本アマチュア無線連盟（JARL）、CQ出版社その他の団体・出版社とは関係ありません。また、過去に刊行された書籍『JARLアマチュア無線ハンドブック』の復刻・改訂版ではありません。

現在は公開準備中です。
