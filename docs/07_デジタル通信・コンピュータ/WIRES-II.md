# WIRES-II ― アナログFM無線機をインターネットにつないだシステム

**WIRES-II（ワイヤーズ・ツー）**は、八重洲無線が2002年にサービスを始めた、アマチュア無線のFM音声とインターネットを接続するシステムです。近くのノード局を経由し、離れた地域のノードや複数局が集まるルームへ接続できました。サービスは**2017年9月30日**に終了しています。

後継の**WIRES-X**は別の仕組みです。ここでは、すでに運用を終了したWIRES-IIの技術と実際の使われ方を扱います。

## システムの構成

```text
利用者のアナログFM無線機
       │ 無線（音声・必要ならDTMF）
近くのノード局の無線機
       │
     HRI-100 ── パソコン・WIRES-IIソフト
                        │
                   インターネット
                        │
             別のノード局・QSOルーム
                        │
                 遠隔地のFM利用者
```

ノードを設置する側には専用のインターフェースやパソコンが必要でしたが、**利用者側のFM無線機は原則としてメーカーを問わず利用できる**のが大きな特徴でした。DTMF機能があれば接続先を指定でき、受信中のノードに接続されている交信を聞く場合は、DTMFが不要なこともありました。

## ノードとルームの接続

WIRES-IIには、接続先のノードを選ぶ方法や、複数局の接続を受け入れるRound Table QSO Roomがありました。

2004年6月の公式更新資料には**RANDOM CALLING FEATURE**として、`#7777D`または`#77777`により、稼働中のノードからランダムに接続先を選ぶ機能が掲載されています。いつもの地域を離れて、知らない地域の局へCQを出してみる楽しみ方もできました。

機能の有無やコマンドの細部はソフトウェアの世代やノード設定によって変わることがあります。

## 当時の実際の利用

2000年代の山梨県甲府市には、7M1FCCによるWIRES-IIノードが存在しました。2007年11月13日版のノード一覧では、**ノード番号5987、145.70MHz、トーン77.0Hz**と記録されています。利用者の証言でもこの周波数と運用は記憶と一致しています。

当時の利用者には、ノードへアクセスして遠隔地の局にCQを出す、あるいは受信中に突然ほかの地域のCQが聞こえてくる、といった体験がありました。ただし、この証言だけで全国的にランダム接続が主流だったとは断定できません。

また、上記のノードは**144MHz帯**であり、WIRES-IIが430MHz帯にしか存在しなかったわけではありません。現在の使用区別を、当時の制度へそのまま当てはめることもできません。

## 汎用性とサービス継続への依存

無線側ではアナログFMとDTMFを活用できたため、ノード側が設備を用意すれば多様な機種の利用者が参加できました。一方、ノード一覧や接続にはWIRES-IIのネットワーク側サービスへの依存がありました。

八重洲無線は**2017年9月30日06:00 UTC**をもってWIRES-IIサービスを終了し、WIRES-Xを案内しました。現在は通常のWIRES-IIネットワークへ当時のまま接続することはできません。歴史的な受信・交信記録、取扱説明書、ソフトウェアの画面、ノード一覧は、システムの復元や研究に役立つ資料です。
