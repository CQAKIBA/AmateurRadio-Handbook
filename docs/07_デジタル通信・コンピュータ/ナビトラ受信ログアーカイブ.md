# ナビトラ受信ログアーカイブ ― 2007・2008年に交わされた短文

1990年代から2000年代にかけて、日本ではアマチュア無線を使って位置と短いメッセージを共有する「ナビトラ」が運用されていました。専用機器が使われなくなった後でも、**当時どのような情報が送られ、人々が何を楽しんでいたか**を知る手掛かりとして、受信情報サイトの記録が残っています。

旧`gps-packet.net`のナビトラ情報サイトには、各地で受信された局の位置、アイコン、メッセージなどを電子地図へ表示する仕組みがありました。[Internet Archiveに保存された2016年9月26日のトップページ](https://web.archive.org/web/20160926140356/http://www.gps-packet.net/)には、「30分以内」「一週間以内」の受信情報へのリンクが残っています。

当時の地図表示用データ`.mps`のうち、2007年と2008年の日付を持つ二つの記録から、**呼出符号・アイコン・短文メッセージだけを抽出した資料**を以下に公開します。緯度・経度などを除外したため、古い地図ソフトや受信設備がなくても、ナビトラの使われ方を直接読むことができます。

[**ナビトラの短文・局アイコン229記録（CSV）**](../assets/data/navitra-gps-packet-2007-2008.csv)

## 残された記録の規模

| 地図表示データの更新日時 | 元の局レコード数 | 情報の対象期間 |
| --- | ---: | --- |
| **2007年7月18日 14:06:42** | **208** | 一週間情報 |
| **2008年5月10日 06:50:13** | **49** | 直近30分のリアルタイム情報 |
| **合計** | **257** | 二つの異なる保存時点 |

二つのファイルには、**コールサイン・アイコン・メッセージが同一の28レコード**が含まれていました。この重複を統合すると**229レコード、異なるコールサイン表記218種類**が残ります。コールサインの末尾の`-1`や`-9`などは、AX.25で複数の端末・用途を区別するSSIDとして原記録のまま残しています。

| アイコンの分類 | 重複統合後の件数 |
| --- | ---: |
| 移動局（方位アイコン） | 81 |
| レピーター | 66 |
| 民家 | 56 |
| その他のアイコン | 26 |
| **合計** | **229** |

これらは**地図表示ソフトが分類したアイコン名**であり、全局の実際の設備や運用形態を個別に確認した結果ではありません。また、一週間の208局と30分間の49局を比べて、運用局数の増減を論じることはできません。

## 当時、20文字で何を伝えていたか

### 日常の一言と移動運用

| コールサイン | アイコン | メッセージ |
| --- | --- | --- |
| JR6LLI-8 | ベル | `サンポニデマス` |
| JJ1IUK-9 | 北北東 | `KM3 バイクデGo! エノシマムケ` |
| JQ3JKG-5 | 西南西 | `スゴイアメ` |
| JL1RTQ | 西 | `コサメ、ヤンダ` |
| JH1KQM-7 | 北 | `FairladyZ` |
| JQ1WPJ-10 | レストラン | `カイシャデ コッソリ ナビトラチュウ` |
| 7K1PTT | ドリンク | `good morning!` |

移動先、天候、使用中の乗り物、日常の出来事から、ちょっとした冗談まで、さまざまな短文が送られていました。**位置情報の伝送という実用機能を使いながら、文字数の制限を一つの遊びとして楽しんでいた**ことが実際の記録から分かります。

| コールサイン | アイコン | メッセージ |
| --- | --- | --- |
| 7K3SGX-13 | 南南東 | `ナビトラック3!バージョン7トン` |
| JK1CNL-10 | レピーター | `KING Gate bayside` |
| JO1ZCE | レピーター | `タテバヤシ U I デジ` |
| JQ1VUE | レピーター | `コガシuidig` |
| 7L1QKS | レピーター | `再開準備中` |
| JG3IMV-11 | 民家 | `431.00MHz Beacon-1` |
| JR2GAI-8 | 東南東 | `試験中　移動局` |
| JF1HCB-5 | 南西 | `チョットオサンポ` |

`UIDIGI`、`WIDE`、`KING Gate`などの名前が繰り返し現れます。これは移動局の位置を知らせる機能の裏側に、**受信局やデジピーターを利用者が設置し、互いの電波を中継するネットワーク**が存在したことを示しています。また、当時の無線機、GPS接続機器、自作ソフトに関するメッセージも読み取れます。

ここに示したものは抜粋です。公開CSVには、**メッセージのないビーコンも含めた229レコード**が収録されており、短文を分類したり、局の用途や当時の機材名を調べたりできます。

## データ形式と保存上の取り扱い

元の記録は、`mapserver script ver = "1.0";`で始まる電子地図向けのテキストデータです。各`point`に緯度・経度、呼出符号、アイコンのグループ番号、受信日時・データ日時・移動速度・方向・メッセージなどが設定されています。**これはAX.25フレームやナビトラの`$PNTS`センテンスを、そのまま記録した生ログではありません。** 地図表示のために変換された情報です。

公開CSVには次の五つの列があります。

| 列 | 内容 |
| --- | --- |
| `snapshot` | 収録元の保存データの日付・期間。二つとも同内容なら`;`区切り |
| `callsign` | 地図表示時のコールサイン表記（SSIDを含む） |
| `category` | 方位アイコンを「移動局」とするなど、閲覧用にまとめた分類 |
| `icon` | 元の地図に記載されたアイコン名 |
| `message` | Shift_JIS系の原文をUTF-8に変換した短文 |

昔の無線通信が受信可能な公開の電波で行われたことと、個人の連絡先や居場所を後年になって再公開してよいかは、別々に考える必要があります。**緯度・経度、個別の受信日時、元サイトの個別局追跡URLは再掲していません。** メッセージ内にあった電子メールアドレスは2レコードで`［メールアドレス省略］`と表記し、ほかの短文は原文を基本として記録しました。全257レコード中、空のメッセージは8件あり、これも削除していません。

元データの同一性を確認するためのSHA-256値は、以下のとおりです。

| 原資料 | SHA-256 |
| --- | --- |
| 一週間情報：`0.mps`（2007年） | `affc5c20b39243157e507493da244056d864e805d62524b4ad7c572f5bd9e781` |
| リアルタイム情報：`1.mps`（2008年） | `ac65ea66e9ed8181a17a918172a856f7406a89013bcffa6d766af28598028886` |

## 残されたものと、分からなくなったもの

**2016年にWebページがアーカイブされた事実は、2016年まで無線の受信・地図情報の更新が稼働していた証拠ではありません。** 今回の二つのデータは2007年と2008年の時点を記録しており、その後いつゲートウェイやサーバーの更新が終了したかは、この資料だけでは確定できません。

かつて日本で盛んだったパケット通信の電子掲示板（RBBS）も、利用者が実際に書いた文章や日々の運用記録が残りにくく、当時どんな交流や実験が行われていたかを後から調べることが困難になっています。ナビトラの短文はわずか20文字程度ですが、**その一つ一つが、当時の無線家の活動を具体的に伝える史料**です。

別の年の`.mps`、ナビトラサーバーの動作記録、NavitraMapの画面や当時の運用資料をご存じの方は、[本ハンドブックのGitHub Issues](https://github.com/CQAKIBA/AmateurRadio-Handbook/issues)から記録を共有できます。
