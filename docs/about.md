# このプロジェクトについて

## 目的

「アマチュア無線ハンドブック」は、現代のアマチュア無線に必要な知識を、共同編集で蓄積するオープンな技術資料プロジェクトです。

運用方法だけではなく、通信方式、無線技術、製作、測定、実験、研究、ソフトウェア、コンピュータ、コミュニティ活動までを対象とします。

## 方針

アマチュア無線は、完成した製品やサービスを利用するだけの趣味ではありません。

既存技術を理解し、自作し、測定し、改良し、新しい使い方や遊び方そのものを考えることも重要な活動です。

そのため、同じテーマでも必要に応じて複数の視点から記事を作ります。

例:

- FT8（運用）
- FT8（技術）
- FT8（信号処理）
- FT8（製作・実験）

## 既存書籍との関係

本プロジェクトは有志による独立した活動です。

一般社団法人日本アマチュア無線連盟（JARL）、CQ出版社その他の団体・出版社とは関係ありません。

過去に刊行された『JARLアマチュア無線ハンドブック』の復刻、複製、改訂版を作ることを目的としていません。

歴史的な資料の目次等を、当時どのような分野が扱われていたかを知る参考資料として利用することはありますが、本文、図版、構成は現代向けに独自に作成します。

## 未完成であることを前提とします

このハンドブックは完成してから公開する書籍ではなく、継続的に更新される資料です。

古くなった記事、誤った記事、分かりにくい記事は、より良い内容へ更新していきます。
