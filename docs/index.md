# アマチュア無線ハンドブック

このページはハンドブック本文の入口です。

> **重要:** 利用・投稿の前に **[ライセンスと利用条件](https://github.com/CQAKIBA/AmateurRadio-Handbook/blob/main/LICENSE.md)** と **[投稿・編集ルール](https://github.com/CQAKIBA/AmateurRadio-Handbook/blob/main/CONTRIBUTING.md)** を確認してください。

本ハンドブックは、アマチュア無線を「使う」ための説明だけでなく、**技術を理解する・作る・測る・実験する・新しい遊び方を考える**ための資料を目指します。

特に初心者が、経験談・伝聞・昔からの常識・極端な成功例を、そのまま一般的な事実として受け取ってしまわないよう、**条件・測定・再現性・一次資料を重視した説明**を目指します。

## この目次について

これは完成形ではありません。

記事を書き始めた結果、

- 1ページでは大きすぎる
- 別の章に置いた方が理解しやすい
- 同じテーマを「運用」と「技術」に分離した方がよい
- 新しい技術や遊び方が生まれた

といった事情があれば、自由に分割・統合・移動します。

本ハンドブックでは、初心者に「そういうものだから」と覚えさせることよりも、**なぜそうなるのか、どんな条件で成り立つのか、実際にはどの程度なのかを確認できること**を重視します。
