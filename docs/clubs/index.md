# クラブ・サークル紹介

アマチュア無線に関する活動を実際に行っているクラブ、サークル、研究会等を紹介するためのページです。

単なる団体名簿ではなく、**何を作ったか、何を実験したか、どのような運用・活動を行ったかが分かる活動ショーケース**を目指します。

## 掲載対象

原則として、次の条件を満たす団体を対象とします。

- 一般に参加可能、または活動内容を一般公開していること
- アマチュア無線に関する活動を実際に行っていること
- 最近の活動実績を確認できること
- 活動内容または成果物が分かる写真・画像を3点以上掲載できること

## 写真について

次のような写真・画像を歓迎します。

- 自作機器
- アンテナ設営
- 測定・実験
- 衛星運用
- ARDF
- 移動運用
- 公開運用
- 製作会
- コンテスト
- 防災訓練
- 展示
- 配布資料・出版物等の成果物

集合写真、懇親会、飲食会等の人物写真だけでは、活動内容を十分に紹介できないため掲載対象としません。

## 更新

紹介記事には最終活動日・更新日等のメタデータを持たせ、将来的には最近更新された団体を上位に表示する仕組みを予定しています。

活動を続け、記事を更新する団体ほど見つけやすくなる構成を目指します。

長期間活動確認ができない記事については、休止表示、一覧からの移動、または整理を行う場合があります。

## 過去のクラブ・活動アーカイブ

活動を終了・休止した団体についても、運用・製作・技術交流の記録を歴史資料として保存します。こちらは現役クラブの活動ショーケースとは異なり、最近の活動実績や新規写真の有無を掲載条件とはしません。

- [YAMA会（横浜・アマチュア・マイクロウエーブ・アソシエーション）](history/YAMA会.md) — マキ電機の工場講習会、全国のマイクロ波実験、富士山ビーコン研究などの記録。

## 掲載内容は永久保証ではありません

掲載された文章や写真は、ハンドブック全体と同様に、必要に応じて編集、整理、置換、削除されることがあります。
