# クラブ・サークル

アマチュア無線のクラブ、サークル、研究会などの活動を紹介します。運用会、機器の自作、測定や研究、イベント、地域での交流など、その団体が実際に取り組んできたことを記録します。

活動の歴史も貴重な資料です。現在の活動状況にかかわらず、現存する団体も過去に活動した団体も同じ一覧に掲載しています。

## クラブ・サークル一覧

**記事の最終更新日時が新しい順**に表示しています。日付はGitHub上で記事のMarkdownファイルが最後に更新された日です。団体の活動日や活動状況を示すものではありません。

## 活動の記録を残す

自作機器、交信・運用実験、アンテナの設営、測定結果、講習会や出展物などの記録があると、実際にどんなことが行われた団体なのかを知ることができます。

昔の写真、会報、製作資料やWebサイトの記録も、活動の歴史を伝える貴重な情報です。新しい活動報告だけでなく、過去の資料や思い出も記事に加えることができます。
