# YAMA会（横浜・アマチュア・マイクロウエーブ・アソシエーション）

**YAMA会**（横浜・アマチュア・マイクロウエーブ・アソシエーション、Yokohama Amateur Microwave Association）は、マイクロ波・ミリ波帯のアマチュア無線を中心に、工作、測定、移動運用、情報交換、共同研究などを行った技術コミュニティである。

神奈川県川崎市にあった[マキ電機](../16_企業・メーカー/マキ電機.md)の工場と密接に結びついていたが、マキ電機の社内クラブではない。製品利用者や工作・実験を行う愛好家が集まる、ユーザー会に近い団体だった。全国各地の無線家が参加し、メーリングリスト（YAMA-ML）や講習会、運用会を通じて活動した。

## 技術を共有するためのコミュニティ

YAMA会の活動は、無線機の所有者が集まる親睦会というだけではなかった。マキ電機の日進町工場で定期的に行われていた「SHF技術アドバイス講習会」は、製品の不具合や自作機器の調整について相談できる場であり、初心者への助言、参加者相互の情報交換、工場の測定器を使った工作・実験の機会でもあった。

[2009年の研究報告][fuji2009]には、講習会を**毎月開催**していたことが明記されている。[個人の24GHzトランスバーター製作記録][homebuilt]には、講習会に機器を持ち込み、スペクトラムアナライザーなどで調整しながら改良を重ねた様子が残る。

マイクロ波・ミリ波帯では、専用測定器や調整技術が必要で、個人がすべての設備をそろえることは難しい。メーカーの工場と技術者の知識が愛好家にも開かれていたという点で、現在のファブラボやメイカースペースにも通じる活動だった。

### ジャンク機器の再利用とミリ波工作

2000年代のマイクロ波・ミリ波工作には、産業用通信機器から取り出された高周波ユニットや測定用部品を再利用する文化があった。新品の高周波部品をすべて買いそろえる代わりに、中古の発振器、ミキサー、アンプ、導波管部品などを集め、周波数変換や組み合わせによってアマチュア帯で使える機器を製作する方法である。

当時の関係者によれば、日本でも2000年代半ばごろまでは、業務用機器の廃品・ジャンクが趣味の工作に使える形で流通しており、47GHzなどの高い周波数帯に挑戦するための貴重な部品供給源になっていたという。部品を持ち寄り、仕様を調べ、工場の測定器を借りて調整できたことが、マキ電機やYAMA会の技術交流の大きな価値だった。

この方法は日本だけのものではなく、1991年の米国のアマチュア無線誌には、余剰機材として出回る[導波管ミキサーなどを活用する記事][surplus1991]がある。また、[47GHzトランスバーターの自作例][47ghzhomebrew]では、かつて37GHzの商用通信設備に使われたモジュールが転用されている。

現在は制御用半導体や設計・製造環境が進歩した一方、特定の中古高周波モジュールを安価に入手できるかどうかは、その時々の廃品市場に左右される。工作の難易度は回路技術の進歩だけでは決まらず、**再利用可能な部品の流通経路と、それを扱う人々の技術交流**にも大きく左右される。

### YAMA-MLと全国の活動

2001年の[Microwave Nagasaki News Letter][newsletter2001]は、JH1UGFによるYAMA-MLの紹介を掲載している。全国のマイクロ波愛好家の情報交換の場となっていた。

各地のクラブ・愛好家が参加する「全国一斉マイクロ波バンド大移動運用会」も活動の一つだった。[JARLの2003年第3回運用会報告][jarl2003]には、全国各地の移動地でパラボラアンテナを展開する様子が記録されている。2013年6月の第22回運用会では、YAMA会と各地実行委員会が主催、JH1UGFが広報・総括を担当すると案内された。[当時の開催案内][event2013]

関係者によれば、会員はYAMA-MLを通じて連絡を取り、参加者のカンパでハムフェアに出展するなど、会の運営を自主的に支えていた。2026年10月時点では、YAMA-MLのシステムが保守されている一方、投稿は見られなくなっているという。

## 富士山測候所を使ったマイクロ波伝搬研究

YAMA会の活動のうち、研究報告として特に詳しい記録が残るのが、富士山頂の旧測候所を利用したビーコン実験である。

### 2009年：24GHzビーコン実験

2009年8月6日から26日にかけて、富士山頂から**24.019000GHz・30mW**の信号を連続送信し、関東各地の受信局が伝搬状況を測定した。特別局のコールサインは **8J1FUJ/1**。セクタービームホーンアンテナを使い、受信側ではWSJTのJT65Cモードで信号対雑音比や周波数の変動を記録した。

実験報告では、常設の受信システム4局、仮設30局が参加し、ハムフェア2009会場でも公開受信が行われた。富士山頂の湿度や降雨による受信信号の減衰などを解析し、気象条件と24GHzの伝搬との関係を調べた。[2009年の研究報告][fuji2009]

### 2010年1月24日：東京大学小柴ホールでの成果報告

この実験成果は、**2010年1月24日（日）**に東京大学本郷キャンパスの**小柴ホール**で開催された、NPO法人「富士山測候所を活用する会」主催の**第3回成果報告会**で紹介された。

[主催者が保存する当日のプログラム][event2010]には、11時15分～12時15分のセッションに、次の発表が掲載されている。

| 項目 | 記録 |
| --- | --- |
| 演題 | マイクロ波帯・ミリ波帯の電波伝搬研究 |
| 発表者 | 横尾富夫 |
| 所属 | 横浜アマチュア・マイクロウェーブ・アソシエーション |
| 共同執筆者 | 槇岡寛幸、岡本嗣男、上條敏生、梅津雅章ほかYAMA会員 |
| 講演資料 | [同題の研究予稿（PDF、4ページ）][fuji2009] |

報告会には高所医学、気象、天文学、宇宙線、大気化学などの発表も並んでいた。大学がYAMA会の研究を主催したのではなく、**東京大学の施設を会場としたNPOの研究成果報告会**である。アマチュア無線家の実測結果が大学・研究機関の研究報告と並んで公開された例として、当時の活動をよく伝えている。

### 2010年：47GHz・24GHz・5.7GHzへの拡張

翌2010年夏には、24GHzに加え、**47.089GHz（1mW）**、**5.759GHz（1W）**のビーコンを使う実験へ発展した。東側の関東地方だけでなく、5.7GHzでは西側の中部・関西方面も受信対象とした。

2011年1月23日の第4回成果報告会（東京大学弥生講堂）に収録された[研究予稿集の34ページから][fuji2010]、新たに作られた47GHz送信機と、**中華なべを反射鏡に利用した5.7GHzパラボラアンテナ**の写真・構成を確認できる。同じ予稿には、共同研究者として槇岡寛幸の所属が「マキ電機」と明記されている。
