# GitHubを使ってハンドブックを編集する

このページ自体が、GitHubを使った共同編集の練習教材です。

## GitHubとは

GitHubは、Gitというバージョン管理システムを利用して、ファイルの変更履歴を管理・共有できるサービスです。

本ハンドブックでは、記事をMarkdownというテキスト形式で保存し、GitHub上で変更履歴を管理します。

## まずは誤字修正から

GitHubを初めて使う場合、最初から新しい記事を書く必要はありません。

1. 修正したいMarkdownファイルを開く
2. 編集する
3. 変更内容をCommitする
4. Pull Requestを作る
5. レビュー後にMergeされる

誤字1文字の修正でもContributionです。

## Markdown

記事本文はMarkdownで記述します。

```markdown
# 大見出し

## 小見出し

これは本文です。

- 箇条書き
- 箇条書き

[リンク](https://example.com/)
```

## Issue

本文を直接編集する自信がない場合は、Issueで情報提供や誤りの指摘をすることもできます。

## Pull Request

変更内容はPull Requestとして提案できます。

Pull Requestでは、元の記事と変更後の記事との差分を確認できるため、共同編集や技術的な査読に向いています。

## 練習

このページに誤字や分かりにくい説明を見つけたら、実際に修正してPull Requestを作ってみてください。

より詳しい操作方法は、プロジェクトの成長に合わせて追加します。
