# 企業・メーカー

アマチュア無線を支えてきた企業、メーカー、工房、販売店などの歴史と製品を紹介します。

無線機や部品の仕様だけでなく、それらを作り、販売し、修理し、利用者と技術を共有した人々の活動も、アマチュア無線文化の一部です。現存する企業に限らず、すでに営業を終了したメーカーも取り上げます。

## 企業・メーカーの記録

| 名称 | 主な分野 | 概要 |
| --- | --- | --- |
| [マキ電機](マキ電機.md) | UHF・SHF・マイクロ波 | トランスバーター、アンテナ、プリアンプ、工作部品を製造販売。工場を拠点とする講習会や技術交流でも知られた。 |

企業の所在地、製品価格、仕様、販売状況は時代によって変わります。各記事の年代表記や製品カタログの発行年月を合わせて読むことで、当時の活動をたどることができます。

廃業したメーカーのカタログ、広告、取扱説明書、製品の実物写真、製作・修理の記録などは、現在も技術的価値を持つ資料です。特に、型番が不明な機器や希少な製品については、写真や銘板、購入時期などの情報が、製品の来歴を知る手掛かりになります。
