# マキ電機

**マキ電機**（マキ電機株式会社、旧・マキ電機製作所）は、神奈川県川崎市を拠点として、UHF帯・SHF帯のアマチュア無線用機器を製造・販売していた企業である。1200MHz帯からマイクロ波・ミリ波帯へ周波数を変換するトランスバーター、アンテナ、低雑音増幅器、工作用の基板・部品などを扱った。

完成品の供給だけでなく、機器の修理・調整、自作支援、マイクロ波技術の講習会を通じて、アマチュア無線家が高い周波数帯を利用するための技術的な拠点にもなっていた。[2008年版総合カタログ][catalog]には製品とともに製作・改造の資料やメンテナンスサービスが掲載され、当時の事業の広がりを知ることができる。

### 川崎・日進町の工場と事業終息

日進町の工場は製造・修理の場であるとともに、愛好家が出入りする技術交流の場でもあった。当時の関係者によれば、工場は日進町の警察署の裏手に長く所在し、ここが活動の中心だったという。

2017年の鶴見区移転については、当時の関係者から、主要な製造・測定設備の多くが移転以前に処分され、従来の事業活動はすでに大幅に縮小していたとの証言がある。移転の事実は報道でも確認できるが、**設備処分の経過や事実上の営業終了時期は関係者証言による**ものである。

## 製品・サービス

2008年12月発行の[総合カタログ第45版（54ページ）][catalog]には、完成品から自作用部品まで幅広い商品が収録されている。

| 分野 | 主な製品・品目 |
| --- | --- |
| トランスバーター | UTVシリーズ。1200MHz、2400MHz、5600MHz、10GHz、24GHz、47GHz帯用など |
| 受信コンバーター | GRX-2402D（衛星通信のSモード受信用） |
| 受信・送受信アンプ | GRシリーズ、GTRシリーズ、CPA・MPAシリーズ等 |
| アンテナ | ループアンテナ、パラボラ、ホーン、スタック用部品等 |
| 自作用ユニット | トランスバーター基板、局部発振器、パワーアンプ、キャビティ等 |
| 電子部品・工作材料 | GaAs-FETなどの半導体、同軸コネクター・リレー、水晶振動子、ケース等 |
| 無線LAN関連 | 2.4GHz帯用アンテナ、プリアンプ、変換ケーブル、分配器等 |
| 技術サービス | 自社製品の動作確認、修理、性能向上改造、局発PLL化等 |

特にトランスバーターは、144MHz、430MHz、1200MHz帯などの既存の無線機を親機として使い、高い周波数帯でSSB、CW、FMなどを運用するための機器だった。キットや基板単位でも製品を扱っており、完成品を購入する以外に、自分で製作・改造する余地が用意されていた。

## 技術支援とアマチュア無線文化

### SHF技術アドバイス講習会

マキ電機では、川崎市日進町の工場を使って「SHF技術アドバイス講習会」が定期的に開かれていた。2009年の[YAMA会による研究報告][fuji]には、同講習会を**毎月開催**していると明記されている。

当時の関係者によれば、講習会は講義を聞くだけの催しではなく、工場の公開日に近いものだった。製品の不具合への対応や初心者への助言のほか、参加者が自作機器を持ち込み、工場の測定設備を利用しながら調整・実験できたという。

その実態は参加者の製作記録からも知ることができる。[24GHzトランスバーターの自作記録][jf1tpr]では、講習会へ自作機を持ち込み、スペクトラムアナライザーによるスプリアスの確認やスタブ調整について助言を受け、改良を重ねる過程が詳細に残されている。

マイクロ波帯は測定器や高周波部品が高価で、独学での調整や故障原因の特定も難しい。こうした設備と経験を共有する機会は、アマチュアが新しい周波数帯へ参入するための実用的な支援だった。現在のファブラボやメイカースペースに通じる性格を持つ活動といえる。

### YAMA会との関係

**YAMA会（横浜・アマチュア・マイクロウエーブ・アソシエーション）**は、マキ電機と密接に結びついて活動したマイクロ波愛好家のコミュニティである。マキ電機の社内クラブではなく、製品利用者や講習会参加者が情報・技術を持ち寄る、ユーザー会に近い性格だった。

関係者の証言によれば、参加者たちはYAMA-ML（メーリングリスト）で情報交換し、カンパを集めてハムフェアへ出展するなど自主的な活動を行っていた。YAMA会はマキ電機を中心としつつ、工場の外でも各地の愛好家が参加する活動へ広がっていた。

2009年にはYAMA会が富士山測候所に24.019GHz・30mWのビーコンを設置し、**20日間の連続送信による電波伝搬実験**を実施した。特別局 **8J1FUJ/1** の信号を複数の受信局で観測し、研究成果は[公開報告書][fuji]に残されている。

この成果は、**2010年1月24日に東京大学本郷キャンパスの小柴ホール**で開かれた、NPO法人「富士山測候所を活用する会」主催の**第3回成果報告会**のプログラムに「マイクロ波帯・ミリ波帯の電波伝搬研究」として掲載された。発表者はYAMA会の**横尾富夫**、研究予稿の共同執筆者にはマキ電機の槇岡寛幸も名を連ねる。会場は東京大学の施設だが、東京大学がYAMA会の研究を主催したという意味ではない。[主催者によるプログラム][fuji2010event]と[発表予稿][fuji]が残されている。

翌2010年にはビーコンが**47GHz・24GHz・5.7GHz**に拡張され、2011年の[第4回成果報告会予稿集][fuji2011]にも研究成果が記録されている。詳しくは[YAMA会の歴史](../clubs/history/YAMA会.md)で扱う。

関係者によれば、YAMA会は2026年時点で実質的に活動を休止しており、MLは維持されているものの投稿は行われていないという。解散を示す資料は確認されていないため、組織の解散と活動休止は区別する必要がある。
