# 交信前準備シート

# **VERSION 1.0**

> **内容は更新される場合があります。** このシートは音声による一般的なアマチュア無線交信を想定した、書き込んで使える準備用メモです。法令、免許条件、使用区別、コンテスト規約などに優先するものではありません。

知らない人と交信するとき、コールサインや無線機の操作だけでなく、**自分が何を伝え、何を伝えないか**を先に決めておくと、落ち着いて応答できます。全部を埋める必要はありません。手元に置く場合は、他人に見られて困る情報を書かないようにしましょう。

名前は通称やハンドルネームでも構いません。住所を細かく公開する必要もありません。**コールサインによる識別は必要ですが、氏名・自宅住所・QSLカードの交換を一般の交信で強制するものではありません。** 特定のコンテストやアワードの参加条件は別途確認します。

## 2. 無線機と周波数の確認

- [ ] 免許を受けた周波数・電波型式・出力の範囲である
- [ ] 周波数の使用区別と、必要な設定（FM/SSB、送信出力など）が合っている
- [ ] アンテナ・給電線・電池残量・音量・スケルチを確認した
- [ ] しばらく受信し、交信中の局がいないか確認した
- [ ] メモと時計を手元に置いた

## 3. 交信の流れ

1. **CQ・応答：** 自局のコールサインを明瞭に送る。
2. **相手局確認：** 聞き取れなければ、聞こえた部分を伝えて再確認する。
3. **レポート：** 了解度と信号の強さを大まかに伝える。分からない数値を無理に細かく読まなくてもよい。
4. **自己紹介：** 決めたオンエアネーム・QTHなどを必要な範囲で伝える。
5. **自由会話：** 話したい内容だけ話す。短い交信でもよい。
6. **終了：** お礼と終了を伝え、適切に自局を識別して終える。

## 4. 困ったときの返答例

| 相手からの要求・状況 | 返答例 |
| --- | --- |
| 本名や苗字を聞かれた | 「オンエアでは○○という名前でお願いします」 |
| 詳しい自宅の場所を聞かれた | 「運用地は○○市まででお願いします」 |
| 紙のQSLカードを求められた | 「今回はノーカードでお願いします」 |
| 電子QSLを利用している | 「eQSLなら対応しています」「LoTWにはアップロードしています」 |
| 電子QSLを利用していない | 「電子QSLも利用していません」 |
| 長話になりそう | 「そろそろ時間なので、これで失礼します」 |
| 繰り返し個人情報を要求された | 「その情報は公開していません。ありがとうございました。73」 |

**紙のQSLカード、eQSL、LoTWはそれぞれ別の仕組みです。** LoTWは電子カード画像の交換ではなく、交信記録の照合サービスです。実際に利用していないサービスを「対応している」と答える必要はありません。紙カードを交換しないためだけに、電子サービスの登録や事務作業を引き受ける義務もありません。

**自分の情報を伝える範囲は、自分で決められます。** 趣味の交信を続けるために、本名・住所・QSLの交換を条件として受け入れる必要はありません。
