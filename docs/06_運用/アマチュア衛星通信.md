# アマチュア衛星通信 ― 世界中の誰かが作った人工衛星で遊ぶ

1961年12月12日、アマチュア無線家たちが製作した小さな人工衛星**OSCAR 1**が宇宙へ飛び立ちました。搭載された送信機はモールス信号を送るだけでしたが、地上からその電波を受信できたのは世界28か国の570人以上の無線家でした。世界初の人工衛星スプートニク1号の打上げから、わずか4年後の出来事です。

アマチュア無線には、無線家、大学、研究グループなどが衛星を製作・打ち上げ、**世界中の無線家がそれを受信したり、衛星を中継器として交信したりできる**文化があります。地上のレピータと似ていますが、中継局は上空数百kmを秒速数kmで飛び、数分から十数分で空を横切っていきます。自宅のアンテナから届く電波が、実際に宇宙の装置を動かして地上へ戻ってくるのです。

## Starlinkとアマチュア衛星は何が違うのか

| 項目 | アマチュア衛星 | Starlinkなどの商業衛星通信 |
| --- | --- | --- |
| 主な目的 | 趣味・自己訓練・無線技術研究・教育、公開実験 | 契約者へのインターネット・通信サービス |
| 開発・運用主体 | アマチュア無線団体、大学、学生、研究者など | 商業事業者 |
| 利用の形 | 開放された機能を使う場合、通常は衛星の使用料・通信契約なし | 端末や利用契約などサービス固有の条件がある |
| できること | 音声・CW交信、パケット、APRS中継、ビーコンやテレメトリーの受信、画像の受信など | インターネット接続や音声・データサービスなど |
| 制限 | 資格・免許・衛星の運用設定・電波法令・短い可視時間・共用上のマナー | サービス提供範囲・契約条件・料金等 |

**「無料で利用できる」ことは、「免許や制限なしで好き勝手に送信できる」ことではありません。** 開放された衛星トランスポンダーは、通常、衛星事業者に交信ごとの料金を払わず使えますが、送信にはアマチュア無線の資格と無線局免許が必要です。実験用のビーコンしか搭載しない衛星もありますし、通信に使える中継器が故障・停止することもあります。特定の大学衛星が誰でも送信できる共用中継器を備えているとは限りません。

一方、**受信から始める**なら、通常、受信そのもののための無線局免許は不要です。アンテナ・受信機・パソコンだけで大学衛星の電波を受信し、復号や測定に参加できます。

## どんな衛星があり、何ができるのか

| 種類 | できること | 代表例 |
| --- | --- | --- |
| **ビーコン・テレメトリー衛星** | モールス、FSKなどで衛星の状態や観測結果を送る。受信と復号・観測記録を楽しめる | OSCAR 1、大学のCubeSat |
| **FMトランスポンダー衛星** | 地上の無線機から送った音声を、別の周波数へ中継して返す。移動運用でも実験可能 | AO-91、SO-50など（稼働状況は変化） |
| **リニアトランスポンダー衛星** | SSBやCWなど、一定の周波数範囲の信号を中継 | AO-7、AO-73など（利用条件は個別に確認） |
| **パケット・APRS衛星** | AX.25パケットのデジピーターとして短い文字・位置情報を再送する | ISSの設備、PCsat、PSAT系の実験 |
| **有人宇宙施設** | 音声中継、パケット、SSTV、学校との交信など。モードや運用予定は変更される | ISS（国際宇宙ステーション）のARISS活動 |

衛星には運用期間があり、同じ衛星でもモードが曜日や時間で切り替わることがあります。名前や周波数だけで使えると思わず、[AMSATの利用可能なFM衛星一覧](https://www.amsat.org/live-fm-satellites/)、[リニア衛星一覧](https://www.amsat.org/live-linear-satellites/)、[利用者による稼働報告](https://amsat.org/status/)で確認します。

## 1961年から続く「自分たちの宇宙インフラ」

| 年 | 出来事 |
| --- | --- |
| **1961年** | 世界初のアマチュア衛星**OSCAR 1**打上げ。手作りのビーコンを世界中の無線家が受信 |
| **1965年** | **OSCAR 3**が初めて地上局の信号を再送信するトランスポンダーを搭載 |
| **1972年** | **AO-6**打上げ。日本でもJAMSAT（日本アムサットの系譜）による衛星通信活動が発展 |
| **1986年** | 日本のアマチュア衛星**JAS-1「ふじ」（FO-12）**打上げ。音声・電信とデジタル通信の実験 |
| **1990年** | **AO-16（PACSAT）**打上げ。蓄積したファイルを受け渡す衛星上のストア・アンド・フォワード通信 |
| **2000年11月13日** | **ISSでアマチュア無線局が運用開始**。国際的なARISS活動の基盤に |
| **2001年** | 米海軍兵学校が製作した**PCsat（NO-44）**打上げ。APRSパケットを衛星で中継する実験が普及 |
| **2010年代以降** | CubeSatの設計・相乗り打上げが普及。大学や学生グループによる衛星と地上局の公開実験が多数登場 |
| **2025年12月2日** | ISSから放出された7機のうち**5機がアマチュア周波数を用いる教育・研究ミッション**。世界各地の受信局がその初期信号を探した |

2025年12月2日にISSから放出された5機は、**SilverSat、RHOK-SAT、Content-Cube、EagleSat-2、Foras Promineo**です。これらの追跡では、[SatNOGS](https://satnogs.org/)の地上局が放出後24時間以内に700回以上の観測を計画しました。軌道投入直後は衛星の正確な軌道や電波の状態が十分に分からないため、**世界中の受信局が実際の電波を探し、周波数とドップラーシフトを照合する**こと自体が宇宙実験になります。[AMSAT：2025年12月の放出・観測報告](https://www.amsat.org/2025/)。

「OSCAR」は*Orbiting Satellite Carrying Amateur Radio*に由来する呼称です。AMSATは条件を満たした衛星へOSCAR番号を割り当てています。ただし、**アマチュア衛星すべてにOSCAR番号が付くわけではありません**。[AMSAT：OSCAR番号の付与方針](https://www.amsat.org/oscar-numbers-policy/)。

大学衛星や実験衛星は現在も新しく登場しています。ただし打上げ数は年により変動し、**「毎年必ず何機の一般開放中継衛星が増える」という保証はありません**。2025年のISS放出実績は[AMSATによる報告](https://www.amsat.org/2025/)で確認できます。多くの大学衛星は、双方向の一般交信用中継器よりも、**ビーコンや観測テレメトリーの公開受信**を主な参加方法としています。

## ISSとARISS ― 宇宙ステーションにも無線室がある

**ARISS（Amateur Radio on the International Space Station）**は、宇宙機関と各国のアマチュア無線家が協力してISS内の無線設備や教育交信を支える活動です。ISSにはアマチュア無線機とアンテナが搭載され、地上との音声交信、FM中継、パケット通信、SSTV画像送信、学校向けの教育交信などに利用されてきました。

**ISSの乗組員との交信**と、**ISS搭載の自動中継器を利用する交信**は別です。乗組員との会話は、乗組員の予定や学校交信などの運用条件に依存し、いつでも呼べば応答してもらえるものではありません。一方、FM中継器やAPRSのデジピーターは、運用が有効なとき、条件に適合した地上のアマチュア局が利用できます。

2025年11月にはISSのアマチュア無線運用開始25周年が祝われました。ARISSによれば、それまでに約1,800回の教育交信を支え、世界中の学校や児童生徒が宇宙飛行士との通信を経験しています。[ARISSの活動紹介](https://www.ariss.org/)。

ISSは常に同じモードで動作しているわけではありません。たとえば2026年10月時点の[ARISS設備状態ページ](https://www.ariss.org/current-status-of-iss-stations.html)には、ColumbusモジュールのFM音声中継と、ロシア側モジュールのAPRS実験に**別々の設備・周波数**が掲載されています。周波数や状態は変更されるため、送信前に必ず直近の情報を確認します。

## ARISS・APRSATという共通エイリアス

[APRS](../07_デジタル通信・コンピュータ/APRS.md)などの[AX.25パケット](../07_デジタル通信・コンピュータ/AX25パケット.md)では、中継局のアドレスを指定してパケットを送ります。衛星の場合にも、個別の呼出符号ではなく、**中継先として共通のエイリアス**を設定する発想があります。

| アドレス | 意味 |
| --- | --- |
| `ARISS` | ISSや一部の衛星のデジピーターが対応してきた共通中継エイリアス |
| `APRSAT` | 複数のAPRS衛星で利用できる共通エイリアスとして提唱された名称 |
| `RS0ISS`、`NA1SS` | ISSで用いられる呼出符号。中継先として利用できるかは動作中の設備設定による |
| 衛星の個別呼出符号 | 衛星ごとの案内で指定される中継アドレス |

`ARISS`は教育活動の名称でもあり、衛星中継のエイリアスでもあります。**同じ文字列でも「ARISSという団体」と「パケットの中継先」は別の意味**です。`APRSAT`は衛星の正式名称ではありません。

エイリアスには「複数の衛星を利用するたびにTNCの設定を変えなくて済む」という利点があります。ただし、全衛星・全時期で動作するわけではありません。APRS開発者Bob Bruninga自身も、ISSの機材構成によって対応可能なエイリアスが変わることを説明しています。[AMSATメーリングリスト（2019年）](https://mail.amsat.org/archives/pipermail/amsat-bb/2019-July/074008.html)／[APRS衛星の運用資料](https://www.aprs.org/pcsat.html)。

説明用のAX.25表示例は、次のようになります。**実際の受信ログではありません**。

```text
JA1ABC>APRS,ARISS:=3540.12N/13942.34E>Via satellite
```

ここで`ARISS`は経路に含まれていますが、**このパケットが実際に衛星に届いたことを示すものではありません**。中継に成功したかはダウンリンクで自局のパケットが再送されたかを確かめます。地上用の`WIDE1-1,WIDE2-1`などを不用意に付け足す必要はありません。

## 衛星通信でできる遊び

- **宇宙からの電波を受信**：CW、FSK、BPSKなどのビーコンを録音し、衛星の位置・姿勢・電源状態などを復号する。
- **ハンディ機による音声交信**：運用中のFMトランスポンダーを介して、地上では直接届かない地域の局と数分間交信する。
- **衛星APRS**：対応衛星のパケット中継を利用して、自局からの短い情報を離れた受信局へ届ける。
- **ISSからのSSTV画像を受信**：ARISSの送信イベントにあわせ、音声で送られた画像をソフトウェアで復号する。
- **大学の宇宙実験に参加**：公開された周波数・データ形式でテレメトリーを受信し、実験主体に受信記録を提供する。
- **追尾装置の自作**：軌道計算、アンテナローテーター、無線機の周波数制御、SDRなどを組み合わせて自動受信システムを作る。

衛星を中継器として利用する場合は、衛星が上空にいる時間と、地上同士の通信できる地域が重なる必要があります。**「世界中で利用できる」とは、同時に地球の裏側まで届くという意味ではありません**。低軌道衛星では、衛星が地平線の上に見えている地域がそのときの通信可能範囲になります。

## やり方 ― まず一機を受信する

### 1. 衛星と通信方式を選ぶ

[AMSATの衛星データベース](https://satdb.amsat.org/)や[SatNOGS DB](https://db.satnogs.org/)で、衛星名、NORADカタログ番号、送受信周波数、変調方式、ビーコン形式を調べます。稼働一覧にあっても一時的に停止することがあるため、受信報告・運用発表を合わせて確認します。

### 2. 空に現れる時刻を調べる

衛星が自分のいる場所から見える時刻を**パス**、地平線からの角度を**仰角**と呼びます。軌道要素データと自局の緯度・経度・時刻を用いれば、次のパスを予測できます。

- [CelesTrak](https://celestrak.org/)：衛星の軌道データを公開。
- [Gpredict](https://github.com/csete/gpredict)：衛星の位置やパス、追尾機材の制御に対応するオープンソースプログラム。
- [SatNOGS Network](https://network.satnogs.org/)：世界中の観測局とその衛星受信記録を確認できる。
- [AMSATステータス](https://amsat.org/status/)：運用者による受信・交信状況の報告。

2026年にはカタログ番号が5桁の上限を超える新しい衛星が登場しています。新しい衛星については、古い**TLE形式だけに依存せず**、CelesTrakのJSONなどのGPデータ形式にも対応した予測ソフトやデータ取得経路を選ぶことが重要です。[CelesTrak：SGP4と軌道データの解説](https://celestrak.org/software/tutorials/sgp4.php)。

### 3. 受信機とアンテナを準備する

144／430MHz帯に対応したハンディ機やオールモード機、SDR受信機などが入口になります。衛星の電力やアンテナによっては、小型のハンディアンテナでも受信できることがありますが、**小電力の大学衛星などでは指向性アンテナや低雑音受信系が必要**になる場合があります。

VHF/UHFの弱い信号には数素子の八木アンテナやクロス八木を向ける方法があります。固定したアンテナだけで受信できるパスもあり、初めから大型の自動追尾装置をそろえる必要はありません。

### 4. ドップラーシフトを考慮する

衛星は高速で移動するため、受信周波数が通過中にずれます。とくに430MHz帯では影響が大きくなります。FM受信機では必要に応じて手動で周波数を補正し、SDRやCAT制御では軌道計算から自動補正できます。送信と受信が別周波数の衛星も多いため、**自分の送信が衛星からどう戻るかを同時に聞ける設備**があると確認しやすくなります。

### 5. 送信して交信する

使用中の衛星のアップリンク周波数、ダウンリンク周波数、CTCSS、対応モードと送信条件を確認します。自局のアマチュア局免許、使用区別、電波型式、占有周波数帯幅の条件を満たしたうえで、必要最小限の出力と短い送信から始めます。

衛星の中継器は**世界中の利用者が数分間のパスを共有する小容量のインフラ**です。長いCQ、不要な高出力、過剰なビーコン、繰り返しの空送信はほかの利用者の機会を奪います。衛星が見える間は、可能なら自局のダウンリンクを監視します。

## オープンソースと自作地上局

アマチュア衛星の醍醐味は、宇宙へ飛ばす衛星本体を持たなくても、**受信・復号・アンテナ・ソフトウェア・通信方式のどこからでも開発に参加できる**ことです。

| ソフト・プロジェクト | できること |
| --- | --- |
| [Gpredict](https://github.com/csete/gpredict) | SGP4を用いたパス予測・追尾、無線機やローテーター制御 |
| [SatNOGS](https://satnogs.org/) | オープンソースの受信地上局を自作し、世界規模の受信ネットワークへ参加 |
| [GNU Radio](https://www.gnuradio.org/) | SDRで受信したデジタル信号を処理し、復調器・デコーダーを自作 |
| [gr-satellites](https://github.com/daniestevez/gr-satellites) | 多数の衛星テレメトリー用デコーダーを集めたGNU Radio系プロジェクト |
| [Dire Wolf](https://github.com/wb2osz/direwolf) | AX.25／APRS衛星の音声AFSKパケット受信・復調 |
| [SatNOGS DB](https://db.satnogs.org/) | 衛星の周波数・変調・観測情報の共有 |

衛星の無線機、ソーラーパネル、マイコン、アンテナが小型化し、大学生や無線家のグループでも実物の宇宙実験を行う時代になりました。その成果を受信する人々が世界中にいることも、アマチュア衛星が半世紀以上続いてきた理由の一つです。
