# 430MHz帯（特記事項等）

430MHz帯の一般的な特徴、周波数の使用区別、通信方式や機材については、[430MHz帯（70cmバンド）](430MHz帯.md)を参照してください。

このページでは、430MHz帯に固有の**占有周波数帯幅30kHzの制限**とその制度史、海外の広帯域通信との違い、個別に認められた実験などを、法令と記録に基づいて扱います。

## 430MHz帯を名指しした30kHz制限

日本の430MHz帯には、**電波型式ごとの一般的な占有周波数帯幅の許容値とは別に、この周波数帯だけを名指しした上限**があります。

2023年9月25日施行の**令和5年総務省告示第81号**「アマチュア局の無線設備の占有周波数帯幅の許容値」の**注7**は、430～440MHz帯の占有周波数帯幅の許容値を、表に定められた値にかかわらず**30kHz以下**としています。

これは「使用区別（バンドプラン）」と同じ規定ではありません。周波数の使用区別を定める**令和5年総務省告示第80号**と、無線設備規則別表第二号第54に基づいて占有周波数帯幅の許容値を定める**第81号**は、別の目的を持つ告示です。使用区別で「全電波型式」とされる区間でも、占有周波数帯幅の技術基準がなくなるわけではありません。

また、**30kHzまでならどの電波型式でも使用できる、という意味でもありません**。電波型式ごとの一般的な許容値や、同じ告示の別の注記（430MHz帯に適用される25kHz以下の規定など）、免許条件、周波数の使用区別にも適合する必要があります。

### 海外の広帯域デジタル通信との違い

海外の430MHz帯では、LoRaを用いたAPRSなど、30kHzを超える広い帯域を使った実験・運用が行われています。例えば欧州のLoRa-APRSでは、**433.775MHz・公称BW125kHz**が広く利用されています。BW250kHzを使用する運用例もあります。こうした広帯域方式や高速データ通信を試すことは、アマチュア無線の技術実験の一つです。

- [LoRa-APRS.org：運用周波数と変調設定](https://lora-aprs.org/settings/)
- [IARU Region 1の会議に提出された433MHz帯LoRa-APRSの提案資料（BW125kHz）](https://vienna.iaru-r1.org/wp-content/uploads/2019/01/VIE19-C5-015-OEVSV-LORA-APRS-433-MHz.pdf)

一例として、オーストリアのアマチュア無線規則は300～3,000MHz帯について、テレビジョン以外の通信方式の占有帯域幅上限を**1,000kHz**と定めています。ただし、各国には周波数の使用区別や共用条件もあり、「海外なら何でも自由」ということではありません。[オーストリアのアマチュア無線規則 §10](https://www.ris.bka.gv.at/GeltendeFassung.wxe?Abfrage=Bundesnormen&Gesetzesnummer=10012930)

一方、日本では、**LoRaの公称BW125kHz・250kHzなどの設定を、一般的な430MHz帯の免許条件でそのまま送信することはできません**。LoRaそのものが一律に禁止されるわけではなく、SX1276／SX1278などには20.8kHz以下の狭帯域設定も存在します。ただし、ICの帯域幅設定と、法令で定義される**占有周波数帯幅の実測値**は同義ではありません。実際の送信スペクトラム、電波型式、免許条件などに照らした確認が必要です。[Semtech：LoRa Connect](https://www.semtech.com/products/wireless-rf/lora-connect)

### 総務省はこの制限をどう説明しているか

2023年のアマチュア無線制度改正に対する意見募集では、**100kHzを超える広帯域LoRa**と、従来の狭帯域通信とのすみ分けを求める意見が提出されました。

これに対して総務省は、占有周波数帯幅の許容値は、他の無線業務との共用のために無線設備が発射できる電波の範囲を定める技術基準であること、今回の規定は既存のアマチュア局の運用状況に沿って定めたことを説明しています。また、周波数の利用状況などに応じて制度の見直しを行う考えも示しています。

この回答は**現行制度の考え方**を説明するものですが、そもそも430MHz帯の上限として**なぜ30kHzという値が選ばれたか**、またその値を**いつ最初に制定したか**を明らかにしたものではありません。

出典：[総務省：制度改正に寄せられた意見と回答（「占有周波数帯幅関係」、27ページ）](https://public-comment.e-gov.go.jp/pcm/download?seqNo=0000250748)

## 30kHzという値の由来をたどる

430MHz帯の30kHzという数字は、2009年の告示で突然現れたものではありません。しかし、**同じ数値が個別の免許条件、古い使用区別、設備の技術基準に登場しても、それらを同一の規制として扱うことはできません**。

ここで、当時の**ATV（アマチュアテレビ）とSSTV（スロースキャンテレビ）も区別**する必要があります。ATVは通常のテレビに近い動画を伝える方式で、画像信号のために比較的広い周波数帯域を使います。一方、SSTVは静止画像をゆっくり走査して音声程度の帯域で伝送する方式です。1958年のCopthorne Macdonaldによる初期のSSTV装置は、120走査線の画像を約6秒かけて送り、2000HzのAM副搬送波を使っていました。これらは同じ「テレビ」の名称を含んでいても、必要な帯域幅が大きく異なります。[1958年『QST』原文](https://bruxy.regnet.cz/hamradio/SSTV_Library/Magazine_Articles/QST_1958_August_-_Copthorne_Macdonald_W4ZZI,_A_New_Narrow-Band_Image_Transmission_System._Part_I_-_Principles_of_Slow-Scan_Picture_Reproduction.pdf)

| 時期 | 確認できる事実 | 制度上の位置づけ |
| --- | --- | --- |
| **1964年1月** | 日本で430～440MHz帯がアマチュア業務に開放。A9によるテレビ映像送信も個別に免許された | 当初からATV実験が認められていたことを示す。ただし一般的な占有帯域幅上限の証明ではない |
| **1965年11月2日** | 435MHzでJA1YNZとJA1DIによる国内初とされるATV交信 | 動画伝送を伴う実際の交信記録。**この日が帯域幅規制の変更日だったわけではない** |
| **1968年3月・8月** | 430MHz帯でのカラーATV伝送と、富士山頂からのATV通信をテレビ番組で実演 | 動画による通信実験の広がりを示す。一般的な許容値の証明ではない |
| **1973年4月10日** | 初回24局のSSTV免許で、430MHz帯のFM方式に**30kHz**が指定されたとの記録がある | **個別免許条件**に同じ数値が登場 |
| **2004年1月** | 平成15年総務省告示第508号の旧使用区別には、特定の電波型式に付される注記として430～440MHz帯**30kHz以下**という記述があった | **2009年以前の明文記録**。全ての電波型式に対する一律上限と同一視はできない |
| **2009年3月** | 平成21年総務省告示第125号の**注3**に430～440MHz帯の30kHz上限を明記 | 占有周波数帯幅の許容値を定める独立した告示 |
| **2023年9月** | 令和5年総務省告示第81号が施行され、旧第125号を廃止。**注7**に30kHz上限を引き継いだ | 現行の上限規定 |

1964年の開放は[JARLの年表](https://www.jarl.org/Japanese/A_Shiryo/A-6_History/History-02.htm)で確認できます。また、[JA9AA円間毅一氏の記録](https://www.icom.co.jp/personal/beacon/ham_life/ja9aa/5166/)には1964年3月2日に435MHz・A9のテレビ送信が許可された実例と、1965年のATV初交信が記されています。1968年のカラー実験・富士山頂からの通信は[JA1BC作間澄久氏の回想](https://www.icom.co.jp/personal/beacon/ham_life/ja1bc/4933/)に詳しく紹介されています。

さらに、[1964年6月3日の衆議院逓信委員会議事録](https://kokkai.ndl.go.jp/simple/detail?minId=104604816X02719640603)には、郵政省担当者が430MHz帯でのアマチュアテレビを認めていることを説明し、放送とは異なる個人的な技術実験としての位置づけを議論した記録が残っています。**これは当時ATVの運用が行政に認められていた証拠**ですが、そこから「当時の430MHz帯には帯域幅の制約が全くなかった」と推定することはできません。

1973年のSSTV免許は[JA3AER荒川泰蔵氏の記録](https://www.icom.co.jp/personal/beacon/ham_life/ja3aer/4883/)で、初回免許の**4月10日**という日付は[JA1COW氏の活動年表](https://www.catv296.ne.jp/~ja1cow/All_About_JA1COW/history_of_ja1cow.html)で確認できます。同年11月22日には第2回の32局が免許されたことも記録されています。ここでの「430MHz帯FM方式30kHz」は、SSTVの画像情報が30kHzを必要としたという意味ではなく、**FM送信設備に対して指定された占有周波数帯幅**です。

2004年の使用区別の**注7**は[JJ1WTLの旧バンドプラン資料](https://jj1wtl.seesaa.net/article/501553392.html)に全文が引用されています（1200MHz帯の変遷記事ですが、共通注記に430MHz帯の規定が含まれています）。年表上の出来事は[アマチュア無線と通信技術の歴史](../15_歴史/history.md)にもまとめています。

### 2022年の750kHz個別指定は「一般解禁」ではない

**JA5FP相田幸久氏**は、資料『[LoRa APRSの製作と運用](https://www.catv296.ne.jp/~ja5fp/lora-aprs.pdf)』の最終ページで、2022年6月22日付の無線局免許状を公開しています。免許状には**750k F1D**の指定が記され、同氏は**平成21年総務省告示第125号の第3項**に基づく個別指定であったと説明しています。430MHz帯のLoRa-APRS実験について、通常の30kHz上限を超える占有周波数帯幅が個別に認められた実例です。

**これは「2022年頃には430MHz帯で750kHzが一般に許可されていた」ということではありません。** 通常の免許手続きで誰もが選べる許容値ではなく、**総務省本省の決裁による個別の特例として扱われた案件**です。公開された免許状と解説から確認できるのは、個別指定の存在と旧告示上の根拠までであり、内部の決裁過程の詳細まで読み取れるわけではありません。

2023年施行の新告示第81号には、旧第125号第3項に相当する個別指定条項が引き継がれていません。ただし、そのことだけから**既に個別指定を受けた免許の現在の効力**や、**別の法的手段による広帯域実験の可否**まで断定することはできません。

この事例は、30kHz制限が撤廃された時期を示す資料ではなく、**一般の制限を超える実験が、個別の行政判断によって認められた記録**として位置づけられます。

## 430MHz帯固有の規定として残る疑問

海外で実用化・普及している通信方式でも、日本の430MHz帯では公称帯域幅が30kHzを超えると一般的な条件のまま実験できません。一方で、この30kHz上限について、**最初に導入された年月日や、430MHz帯にその値を選んだ技術的・行政的な理由は確定していません**。

総務省の制度改正時の回答、古い告示、実際の個別免許は、それぞれ異なる観点からこの規定を知る手掛かりになります。古い無線設備規則・告示・免許状・工事設計書や、制定時の審議資料などをお持ちの方は、[GitHub Issues](https://github.com/CQAKIBA/AmateurRadio-Handbook/issues)から情報を共有してください。とくに**30kHzの数値を最初に導入した規定と、その理由を示す資料**が重要です。

現在の送信可否は、歴史上の実例だけで判断せず、現行の法令、周波数の使用区別、各局の免許条件によって確認する必要があります。
