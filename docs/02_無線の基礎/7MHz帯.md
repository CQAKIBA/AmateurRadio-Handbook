# 7MHz帯（40mバンド）

7MHz帯は、日本国内のさまざまな地域や、アジア諸国をはじめとする外国のアマチュア局と交信を楽しめる短波帯です。**昼間には国内の声がにぎやかに聞こえ、夕方から夜間には外国の信号が増える**ことがあります。SSBによる会話、モールス通信（CW）、FT8など、同じ周波数帯に異なる遊び方が同居しています。

日本では**7.000～7.200MHz**をアマチュア無線に使用できます。米国などのITU Region 2では7.300MHzまで使用できる国もあり、外国局が聞こえる周波数のすべてで日本の局が送信できるわけではありません。

| 基本項目 | 7MHz帯の特徴 |
| --- | --- |
| 通称 | **40mバンド**。波長はおよそ43m |
| 日本での使用範囲 | **7.000～7.200MHz**。7.000～7.030MHzはCW、7.030～7.200MHzは狭帯域の全電波型式（詳細は使用区別を参照） |
| 身近な交信 | 日中を中心とする国内SSB、CW、FT8、移動運用、アワード・コンテスト |
| 遠距離交信 | 夜間や夕方・朝方のアジア方面、条件によってさらに遠方 |
| 注意点 | HFアンテナの設置、人工雑音、時間帯による伝搬の変化、モードごとの運用慣行 |

日本の基本的な区分は[JARLの2025年7月17日施行バンドプラン](https://www.jarl.org/Japanese/A_Shiryo/A-3_Band_Plan/A-3-0.htm)によります。このページで挙げる**慣用周波数は特定の局やグループの専用周波数ではありません**。地域、曜日、時間帯、コンテスト、技術の普及によって利用状況は変化します。

## 伝搬特性

7MHz帯では、電離層で折り返された電波によって地平線の向こうの局と交信できます。国内だけでなく外国の局まで直接届く一方、**いつでも同じ方向・距離へ届くわけではありません**。

| 時間・条件 | 聞こえやすい相手と特徴 |
| --- | --- |
| **朝～昼** | 国内の数百km前後から広い範囲の交信を期待できることが多い。太陽活動、季節、電離層によって近距離が聞こえにくいこともある |
| **夕方～夜** | 近場より遠方の信号が優勢になり、アジア諸国やさらに遠いDX局が聞こえる機会が増える |
| **夜明け前後** | 日照の境界線（グレーライン）付近など、遠距離の信号が強まる場合がある |
| **伝搬が悪い日** | 昼間でも国内局が弱い、特定の地域だけ聞こえない、急にフェージングが大きくなる、といった変化が起こる |

昼間は上空に向けて出た電波が比較的近距離へ戻る**NVIS（Near Vertical Incidence Skywave）**の伝搬が役立つ場合があります。夜間には電離層の吸収が弱まり、遠距離の電波が聞こえやすくなる傾向があります。ただし、これらは時刻を固定した約束ではありません。同じ日本国内でも、北海道から九州、沖縄や離島までの経路によって状態が違います。

アンテナの高さも重要です。低い水平ダイポールは高い仰角へ電波を放射しやすく国内向けの交信と相性がよい場合があります。高く設置したアンテナや垂直系アンテナは低仰角の遠距離信号を狙いやすいことがあります。**送信出力だけでなく、アンテナの設置条件が交信できる地域を変えます。**

実際、2025年の移動運用記録には、7MHzでも伝搬の不安定な時間があったことが報告されています。[月刊FBニュース：日本全国・移動運用記（2025年3月）](https://www.fbnews.jp/202503/unnyouki/)。

## 周波数の詳細解説

### 周波数表の読み方

次の表は、**7.000MHzから7.200MHzへ、周波数の低い順に**並べています。使用区別と、実際に使われている周波数や慣行を同じ表に載せていますが、両者の意味は違います。

- **使用区別**：日本で使用できる電波型式などを定める規則・JARLのバンドプラン。
- **主催団体等の指定・案内**：コンテストの使用区間、通信ソフトの運用周波数、イベントの運用案内など。
- **運用記録**：交信日や具体的な周波数が分かる記録。**その日に使われた**事実を示し、毎日の活動量を保証しない。
- **慣行・伝承**：過去の周波数案内や個人の経験に残る話。具体的な運用記録が見つからない場合は、事実として確定せず「要情報提供」と示します。

**「伝承・要情報提供」と記した行は、該当する使われ方が語られてきた痕跡はあるものの、独立した交信・受信記録による裏付けが確認できていない情報**です。現在もその使い方が続いているという意味ではありません。日時、周波数、モード、運用地域などの分かる記録があれば、[本ハンドブックのGitHub Issues](https://github.com/CQAKIBA/AmateurRadio-Handbook/issues)から情報をお寄せください。

表中の**「付近」や「範囲」は、特定の周波数を占有したり優先したりする権利を示しません**。データ通信の代表周波数には、無線機の**ダイヤル表示周波数**を示したものがあります。USBで音声周波数の信号を重ねて送信する場合、電波の実際の周波数は表示値より高い側に広がります。

#### 日本独自の国内FT8、海外で一般的なFT8

7.041MHzと7.074MHzは、その違いがわかりやすい例です。7.041MHzは国内FT8を楽しむ局が集まる慣行として使われ、2025年の[ALL JA1コンテスト](https://ja1zlo.u-tokyo.org/allja1/37rule/)でも採用されました。一方、7.074MHzは国際的なFT8の標準的な周波数として広く知られます。

ただし、**7.074MHzで国内局同士が交信してはいけないという意味ではありません**。2023年の国内使用区別の見直し以前に存在した制約を含む古いWeb記事には注意が必要です。[国内運用者による制度変更を反映した説明](https://ja4joe.livedoor.blog/archives/16922185.html)。

また、WSJT-Xの初期設定には7.041MHzが登録されていないことがあります。[2026年の設定例](https://note.com/ja1bjt/n/n6d6dfa5be840)では、国内用の周波数を手動で追加しています。

#### DXと国内向けの範囲は、はっきり分かれている？

7MHz帯は国際的に使われるため、7.000～7.200MHzの範囲に国内局と外国局が混在します。米国などでは7.200～7.300MHzも使えるため、**海外でよく使われる周波数でも日本の局が送信できるとは限りません**。

また、国内のコンテスト、SSB移動局、国際的なFT8、海外のデジタル音声などが近い範囲に存在することがあります。「国内専用」「DX専用」「常連の周波数」といった呼び方は、法令で分けられていない限り、実際の交信・受信記録とその時期を確かめる必要があります。

## 使われている通信方式

| 方式 | 7MHz帯での位置づけ |
| --- | --- |
| **SSB（主にLSB）** | 国内の音声交信の中心的な方式。海外との音声交信も可能。大きな信号が出ていない時間もある |
| **CW（欧文・和文）** | 国内外の交信、コンテスト、和文の定例交信。モールス符号の練習と交信は別の楽しみでもある |
| **FT8** | 国内7.041MHz、国際的には7.074MHzが知られる。短い定型メッセージで弱い信号も復調しやすい |
| **FT4** | 2025年の国内コンテストでは7.038MHz、国際的には7.0475MHzの利用案内がある |
| **WSPR** | 伝搬の観測が中心。自動的な受信報告を集められるが、一般的な双方向交信とは目的が異なる |
| **RTTY・PSK31・JT65・JT9** | 歴史のあるデータ通信。運用記録や周波数の慣行は残るが、2026年にいつでも相手がいるとは限らない |
| **SSTV・デジタルSSTV** | 画像を送る遊び。国内外の周波数案内はあるが、対応ソフトと活動中の相手が必要 |
| **FreeDV** | デジタル音声。公式案内に40mの活動周波数があるが、SSBほど頻繁に音声が聞こえるとは限らない |
| **JS8Call・Olivia・その他の狭帯域データ** | 文字交信や実験に使われる方式。運用事例・周波数資料はあるが、相手を事前に探す方が確実 |
| **AM・その他** | 狭帯域の条件に適合すれば技術的に可能な方式がある。通常のSSBと同じ頻度で使われているとは限らない |

7MHz帯では、単に「デジタル通信が可能か」だけでなく、**ソフトウェア、無線機の音声入出力、時刻同期、運用周波数が相手と合うか**を確かめることが大切です。

## 実際の使われ方と運用文化

### 昼間の国内SSB・移動運用

7MHz帯のSSBは、国内の移動局や地域の異なる局を探す楽しみがあります。2025年には、[宮崎県の移動局を昼間に受信して交信した記録](https://ja3cgz.com/7mhzssbqso-portable6/)で、当日の帯域が混雑していたと報告されました。また[松戸アマチュア無線クラブの2025年3月の記録](https://ja1ygt.wordpress.com/2025/03/26/令和7年3月22日の移動運用/)には、公園から7MHz帯SSBを使った運用が記されています。

こうした記録から、平日昼間や休日の移動運用を探すと交信相手に出会える可能性があります。ただし、**一日の大混雑が一年中続くという意味ではありません**。電離層の状態が悪ければ、多くの無線局がいても聞こえないことがあります。

### CWの短い交信と、和文の長い交信

CWには、コールサイン・RST・名前・所在地を短く交換する交信と、和文や欧文で会話を楽しむ交信があります。2025年の[A1 CLUB和文オンエアミーティング](https://jf0rrh.com/entry/2025/01/02/165744)では、具体的な周波数と比較的ゆっくりした送信速度が告知されています。

一方、コンテスト中は短時間の交信が多くなり、初心者には速すぎる場合があります。交信内容や速度が合う相手を見つけることも楽しみ方の一つです。

### アワード・コンテスト・イベント

国内の市・郡・区、移動地点、記念局などを集めるアワードでは、特定の場所へ移動して交信する局が現れます。コンテストでは7MHz帯のCW・SSBの使用区間が定められ、一時的にバンドの様子が変わります。イベントの規約や告知から、そのときの交信相手を探せます。

デジタル通信でも、2025年のALL JA1コンテストはFT8/FT4の7MHz部門を設けています。**コンテスト周波数は期間・大会ごとの規約に従う**もので、すべての日時でその用途が独占されるわけではありません。

## 交信相手の見つけ方

**国内の声で交信したいとき**は、まず昼間に7.1MHz台を含むSSB区間をLSBで聞き、運用している局の呼出し方や混み具合を確かめます。日によっては低い方の電話運用周波数にも国内局がいます。コンテスト開催日には7.060～7.140MHzなどで普段と違う交信が聞こえます。

**FT8を試すとき**は、国内相手なら7.041MHz、海外局も含めるなら7.074MHzを受信して、実際のデコード数を比較できます。[PSK Reporter](https://pskreporter.info/pskmap)で自分の受信・送信の到達状況を調べる方法もあります。受信報告は相手との交信成立を保証しません。

**CWや和文を探すとき**は、7.000～7.030MHzを聞き、[A1 CLUB](https://a1club.org/)などのオンエアミーティングやイベントの案内も手掛かりになります。

**SSTVやFreeDVなどの比較的珍しい方式**では、活動日の案内、[FreeDV Reporter](https://qso.freedv.org/)などのリアルタイム表示を使うと、漫然と周波数を聞くより相手を探しやすくなります。

## 無線機・アンテナ・必要な機材

7MHz帯では**約43mの波長**に対して、一般的な半波長ダイポールアンテナは全長約20m、1/4波長の垂直アンテナは約10mが目安です。どちらも実際の構造・高さ・周囲の影響で寸法や性能が変わります。

| 機材の例 | できること・注意点 |
| --- | --- |
| **7MHz帯に対応したHF SSB/CW機＋屋外ダイポール** | 国内の音声・CWの標準的な構成。アンテナを広げるスペースと給電線、適切な設置方法が必要 |
| **HF SSB機＋パソコン＋音声・制御接続** | FT8/FT4などのデータ通信。時計の同期、適切な音声レベル、送信周波数の確認も必要 |
| **HF用モービルホイップ** | 車両や移動先・狭い設置場所でも挑戦できる。基台、対向電流の経路、周囲の金属、損失が結果を大きく左右する |
| **マグネチックループや短縮アンテナの自作** | 限られた場所で工夫できる。共振の調整が鋭敏で、小型ループでは高周波電圧が高くなるため安全に配慮する |
| **移動先の仮設ワイヤー** | 自宅に大きなアンテナを置けない場合の選択肢。設置許可、周囲の人、電線、転倒・落下に注意 |
| **受信だけから始める設備** | HF受信機や対応するSDRとアンテナで、SSB・CW・データ信号の活動を調べられる。送信しない受信実験にも価値がある |
| **インターネットを利用した受信** | ボランティアなどが設置・公開する[KiwiSDR](https://rx.kiwisdr.com/)、[WebSDR](https://websdr.org/)、[AirspyのSpyServer公開受信機](https://airspy.com/directory)を利用すれば、受信機やアンテナを購入せず7MHz帯の電波を聞ける。Airspyは受信機の名称で、SpyServerでは専用ソフトが必要な場合がある。各公開局の受信可能周波数や利用条件を確認する |

**7MHz帯は無線機やアンテナの自作を楽しむ人にも使われています。** 2025年には[7MHz用QRP CWトランシーバーの製作記録](https://ja7gsa.hatenablog.com/entry/2025/10/17/231837)や、[小出力CW送信機の試作・測定記録](https://ameblo.jp/xts-hiro/entry-12888296538.html)が公開されています。後者は作者自身が送信機の規格適合や手続を検討しており、**自作機を実際に電波として送信するには法令に適合した設備・免許上の条件が必要**です。

大型アンテナが張れないからといって7MHz帯を諦める必要はありません。2026年7月の[移動運用報告](https://toki599.bbs.fc2.com/?pos=20)には、モービルホイップと比較的小さな出力による7MHzの交信実績が紹介されています。ただし、**小型アンテナで交信できたという事実は、短縮による損失がないという意味ではありません**。

アンテナチューナーでSWRを下げることと、電波を効率よく放射することは別です。設置方法の改良、使用するモードの選択、運用時刻の変更などを組み合わせると交信できる可能性を広げられます。

## 受信環境とノイズ対策

### HF機を買ったのに何も聞こえない？

7MHz帯は、**アンテナで受けた自然の雑音や人工雑音の中から小さな信号を探す**通信です。買ったばかりの無線機で何も聞こえなくても、いきなり故障と決めつける必要はありません。

近くにある電気機器が7MHz帯へ雑音を出している場合、強いノイズによって遠くの局が埋もれてしまいます。特に見落としたくないのが、**家庭内の電源配線でインターネット通信を行うPLCアダプター**です。電力線に高周波信号を重ねる方式で、JARLはHF帯への妨害の可能性について以前から技術的な調査を公表しています。

PLCだけでなく、LED照明、ACアダプター、PC電源、充電器、太陽光発電のパワーコンディショナー、近隣の電気設備なども雑音源になることがあります。**音の特徴だけで原因機器を決めつけず、実際に切り分けること**が重要です。

### ノイズ源を調べる順序

1. **同じ周波数・モードで時間を変えて受信する。** 電離層の状態が悪いだけなのか、常に強いノイズが出ているのかを観察する。
2. **アンテナを外したときのノイズの変化を確かめる。** 大きく変わるなら外から拾っている可能性がある。変化しなければ無線機の電源や近くの機器も疑う。
3. **PLCアダプター、充電器、PC電源、LED照明などの電源を一つずつ切ってみる。** 受信のSメーター表示やスペクトルを記録すると比較しやすい。
4. **バッテリー駆動の受信機を使い、場所を変えてみる。** 部屋・ベランダ・屋外・移動先でノイズが変わるなら、設置環境が原因である可能性が高まる。
5. **自宅の機器でなければ、近隣設備や電力線の雑音も疑う。** 感電の危険がある設備を自分で開けたり、電柱や電線に触れたりしない。必要に応じて管理者や専門家へ相談する。

[ARRLのRFI調査ガイド](https://nediv.arrl.org/rfi-troubleshooting-guide/)にも、バッテリー受信機を使って家庭内外の雑音を区別する方法が説明されています。配電盤の操作は、安全に扱える人が行う必要があり、**通電部を露出させた調査はしません**。

!!! tip "高性能な無線機に買い替える前に"
    **PLCアダプターなど身近な機器の電源を切っただけで、今まで聞こえなかった7MHz帯の局が聞こえるようになる可能性があります。** 無線機の感度不足と人工雑音による受信不能を区別できれば、費用をかけずに問題を解決できる場合もあります。

## よくある問題と解決方法

| 症状 | まず試すこと |
| --- | --- |
| **昼間でも国内局が聞こえない** | 時間帯・季節を変える。ほかの受信場所で比較する。アンテナと同軸の接続、ノイズ源を調べる |
| **大きなダイポールを設置できない** | 短縮アンテナ、マグネチックループ、移動運用、FT8・CWなどを検討。安全条件と損失を理解して選ぶ |
| **SSBの会話が聞こえても相手に届かない** | LSB/USB設定、電力、アンテナの整合・設置・効率、受信局の距離、相手が呼出しを受け付けているかを確認 |
| **FT8で7.041MHzが選べない** | WSJT-X等の周波数設定へ国内周波数を追加する。無線機の実際の送信範囲とオーディオ周波数も確認する |
| **FT8の数字は見えるが交信できない** | PCの時刻、送受信切替、音声レベル、送信出力、周波数、相手の受信状態を確認 |
| **コンテストで急に混雑した** | 開催日・規約を確認し、空いた区間や別の時間を選ぶ。慣れない人は受信で交信手順を学ぶこともできる |
| **知らない方式の信号ばかり聞こえる** | SDRのウォーターフォールや音声サンプルからモードを調べる。信号が聞こえるだけでその方式の常時活動は保証されない |
