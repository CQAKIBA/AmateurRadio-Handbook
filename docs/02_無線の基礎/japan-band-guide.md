# 日本のアマチュアバンドを選ぶ ― どんな電波が飛んでいる？

アマチュア無線を始めるとき、まず決めたいのは「どの無線機が高性能か」よりも、**誰と、どんな通信をしたいか**です。同じ無線局の免許でも、7 MHz帯と430 MHz帯では、交信相手の探し方も、必要なアンテナも大きく違います。

近所の人と気軽に話したい。遠くの県と交信したい。世界の電波を受信したい。文字や画像を送ってみたい。人工衛星と交信したい。どれもアマチュア無線ですが、**一台の小さなトランシーバーで何でもできるわけではありません**。

また、周波数の使用区別で「送信できる」ことと、そこで「交信相手が見つかる」ことも別です。日本のどこに住み、どこへアンテナを設置でき、いつ運用するかによって、最初に選ぶべきバンドは変わります。

## まず、どんな交信をしたい？

| やりたいこと | 最初に調べたいバンド・方式 |
| --- | --- |
| 徒歩・自転車・車などで、近隣の局と声で話す | **144 MHz帯・430 MHz帯のFM**。周囲に実際の利用者がいるか、地形や建物で届くかが重要 |
| 自宅から日本各地～アジア諸国の人と声で話す | **7 MHz帯のSSB**。国内から近隣のアジアまで、伝搬条件によって交信できる。HFアンテナの設置を工夫するのが最初の難関。短縮ホイップや小型ループ、自作などの道もある |
| 海外の人と声で話したい | **14・18・21・28 MHz帯などのSSB**。資格、電離層の状態、時間帯、アンテナによって交信できる地域が変わる |
| 大きなアンテナを置けないけれど、遠くと交信したい | **HF帯のFT8（WSJT-Xなど）**。小さな信号から短いメッセージを復調する方式。小型アンテナでの挑戦にも向くが、対応無線機もしくは簡単な自作回路と、PCが必要 | 
| モールス信号で交信することに憧れる | **HF帯などのCW（モールス通信）**。符号を覚え、送受信を練習する楽しさがある。小電力でも交信できる可能性がある一方、慣れるまで練習が必要 |
| 位置情報や短いデータを流したい | **144/430 MHz帯のAPRS・パケット通信など**。対応機器と運用区分が必要 |
| 画像やデジタル音声を試したい | **SSTV・RTTY・APRS・D-STARなど**。周波数だけでなく通信方式の一致が必要 |
| 人工衛星やISSとの通信に挑戦したい | **144/430 MHz帯などの衛星通信**。衛星の出現時刻、送受信周波数、アンテナが重要 |
| まだ誰も試していない通信や、市販品の少ない世界を開拓したい | **1200 MHz帯以上のマイクロ波や独自の通信実験など**。無線機・アンテナ・通信方法まで作り、仲間と試す楽しみがある |

これは運用の入口を示すもので、資格・免許による操作範囲や個々のバンドの使用区別まで表したものではありません。日本の現行の区分は[JARLアマチュアバンドプラン](https://www.jarl.org/Japanese/A_Shiryo/A-3_Band_Plan/A-3-0.htm)で確認できます。

## 「バンド」と「通信方式」は別の選択

**バンド**は使用する周波数帯です。一般に周波数が低いほどアンテナの寸法が大きくなり、電離層を利用する遠距離通信が身近になります。周波数が高くなると小型アンテナが使いやすくなりますが、地形や建物の影響を強く受け、遠くの局と直接交信するには見通しや特別な伝搬経路が重要になります。

一方、**通信方式（モード）**には、FM、SSB、AM、CW、FT8、画像通信、デジタル音声などがあります。同じ7 MHz帯の中にも、声で話す局と、モールス符号やデータを送る局がいます。144 MHz帯にもFMだけでなく、SSB、CW、データ通信、衛星との交信があります。

**FM専用のハンディ機を購入しても、一般的なSSB交信やHF帯のFT8をそのまま受信・送信できるわけではありません。** 逆に、HF用のSSB無線機だけでは430 MHz帯のFMレピータは利用できません。無線機を選ぶときは、対応バンドと対応モードを必ず別々に確認しましょう。

近年はFT8、画像、デジタルデータなどを利用できる環境が広がっています。2023年には日本のアマチュア無線の制度が見直され、周波数等の一括表示や設備変更の手続の簡素化なども行われました。ただし、**どんな無線機でも設定を変えるだけで全モードを使えるわけではなく**、無線局の設備・免許条件に適合させる必要があります。

## 短波（HF）：日本中、さらに海外の局にも届く

HF帯では電離層によって電波が地上へ戻ってくるため、見通しの届かない県や外国と直接交信できます。ただし、電離層の状態が常に同じではないので、**同じ設備でも昼夜・季節・太陽活動によって聞こえる局が入れ替わる**のが特徴です。

| バンド | どんな通信が期待できる？ | 初めて使うときの現実 |
| --- | --- | --- |
| **1.8/1.9 MHz帯** | 夜間の国内・海外DX、CW・データ・電話など | 波長が非常に長く、アンテナとノイズ対策が難しい。小さな住宅から始めるには工夫が必要 |
| **3.5/3.8 MHz帯** | 夜間から早朝の国内交信。冬場の長距離通信も | 国内の使用可能な周波数が飛び飛びになっている。大型アンテナ、都市部の受信ノイズに注意 |
| **7 MHz帯** | 昼間の国内SSB・CW・FT8などに加え、時間帯や伝搬条件が合えばアジアなど海外とも | 声で国内外の局を探す有力候補。アンテナを短くすると効率が落ちやすいが、短縮や設置場所の工夫による運用例もある |
| **10 MHz帯** | CWや狭帯域データで国内外と交信 | 日本では通常のSSB・AMによる音声通信には使えない。声で話すためだけに選ばない |
| **14 MHz帯** | 国際交信、SSB・CW・FT8など。条件により国内も | 世界の局を探す定番の一つ。資格による運用制限があり、国内の雑談がいつも聞こえるとは限らない |
| **18 MHz帯** | 国内外のSSB・CW・データ通信 | 14 MHz帯や21 MHz帯と違う伝搬条件を楽しめる。電離層の状態で活発さが変わる |
| **21 MHz帯** | 国内・海外のSSB・CW・FT8など | 太陽活動が活発な時期は遠距離交信が楽しい。状態が悪いと驚くほど静かなこともある |
| **24 MHz帯** | 遠距離のSSB・CW・データ通信 | 電離層が開くのを待つ楽しみがある。国内の会話相手をいつでも探す用途には向かない |
| **28 MHz帯** | SSB・CW・FT8・FMなど。太陽活動やEsによる遠距離交信 | 短波の中ではアンテナを比較的小さくできるが、常に遠くへ届くわけではない |

**日本各地からアジア諸国まで、声による交信を試したいなら7 MHz帯は有力な候補です。** 電離層の状態が変われば、昼間は国内、夕方や夜間には海外の局が聞こえることもあります。受信だけでも時間帯による違いを楽しめます。ただし、交信相手の数や届く地域は一定ではありません。

## VHF・UHF：近所の局、移動運用、意外な長距離通信

50 MHz帯以上では、通常の地上間通信はアンテナ同士の見通しや地形が重要になります。特に144・430 MHz帯は小型のハンディ機や車載機が使いやすく、**大がかりなHFアンテナを設置できない人にも選択肢があります**。

ただし、小型アンテナで運用しやすいことと、どこからでも誰かにつながることは別です。建物の奥や谷間からでは近くの局の電波も届きにくくなります。

| バンド | 主な楽しみ方 | 相手を見つける条件 |
| --- | --- | --- |
| **50 MHz帯（6 m）** | FMによる近隣交信、SSB・CW・FT8、Esによる国内・海外との交信 | 普段は静かでも、特に春～夏のEsで遠方の信号が急に増えることがある |
| **144 MHz帯（2 m）** | FMの近隣・移動交信、SSB・CW・データ通信、衛星、異常伝搬 | 周囲の利用者、地形、アンテナの高さ次第。FMとSSBでは交信相手のいる場所も違う |
| **430 MHz帯（70 cm）** | FMの近隣交信、レピータ、D-STAR等のデジタル音声、APRSなどのデータ通信、衛星 | 都市部や移動先で便利な場合がある一方、地域や時間によってはFMでほとんど声が聞こえない |
| **1200 MHz帯（23 cm）** | 近距離交信、レピータ、データ通信、マイクロ波技術・アンテナ実験 | 運用局・対応無線機が少なめ。相手と日時を合わせる運用やイベントが有効 |
| **2400 MHz帯以上** | 高速データ・画像・マイクロ波通信、衛星、アンテナ・回路研究 | 市販設備の選択肢と一般交信の機会が限られる。製作・測定・共同実験との相性がよい |

135 kHz帯と475 kHz帯のような長波・中波のアマチュアバンドも存在します。これらは長い波長、アンテナ効率、送信条件などの面で技術的な挑戦が大きく、初めて誰かと音声交信するための一般的な選択とは異なります。

## 声を使わず遠くとつながる：FT8とCW

### FT8 ― 小さなアンテナでも遠くと交信したい

**FT8**は、微弱な信号に含まれる短いメッセージをコンピューターで復調して交信するデジタル方式です。**WSJT-X**はFT8など複数の弱信号通信方式を扱うソフトウェアで、FT8では交互に約15秒ずつ送受信を繰り返し、コールサインや信号レポートなどを交換します。

SSBの音声では交信できないほど弱い信号でも復調できることがあり、**大きなアンテナを設置できない人が、遠くの局との交信に挑戦する有力な選択肢**です。数Wの出力や妥協したアンテナでも海外交信が成立する場合があります。ただし、アンテナの損失や建物による遮蔽がなくなるわけではなく、伝搬・雑音・相手局の設備にも左右されます。

通常は、使用するバンドのSSBに対応した無線機、パソコン、音声・制御の接続、時刻を合わせる手段などが必要です。**FM専用のハンディ機だけでHF帯のFT8を運用することはできません。** また、自由な会話よりも、短い定型メッセージを交換する交信に向いています。

参考：[WSJT-X公式ユーザーガイド](https://wsjt.sourceforge.io/wsjtx-main_en.html)。

### CW ― モールス通信への憧れを交信に変える

**CW（モールス通信）**は、短点と長点の組み合わせで情報を伝える通信方式です。電鍵を操作して遠くの誰かと交信するという体験そのものに魅力があり、符号を少しずつ聞き取れるようになる過程も楽しみの一つです。

CWは狭い周波数幅で受信できるため、雑音の中から小さな信号を取り出しやすく、**小電力や簡素な送信設備でも、条件が合えば遠距離へ届きます**。コールサインと信号レポートなどを交換する短い交信から始めることもできます。

一方、電波が遠くへ届くことと、人間がモールス符号を送受信できることは別です。慣れた人の交信は速く、初心者が耳と手で通信を楽しむには練習が必要です。**手軽に遠距離交信するための近道というより、モールスを使ってみたい人にとっての魅力的な目標**です。ゆっくりした符号の受信練習から始められます。

参考：[ARRL：モールス符号を学ぶ](https://www.arrl.org/learning-morse-code)／[ARRL：CWとは](https://www.arrl.org/cw-mode)。

!!! warning "資格と免許の操作範囲にも注意"
    日本では、10 MHz帯と14 MHz帯の送信には第一級または第二級アマチュア無線技士の資格が必要です。18 MHz帯は第三級以上で使えますが、第四級では使えません。一方、7 MHz帯や21 MHz帯は第四級でも条件の範囲内で運用できます。

    **無線機が対応しているバンドやモードでも、自分の資格と無線局免許が対応していなければ送信できません。** 詳しくは[日本無線協会の資格別操作範囲](https://www.nichimu.or.jp/denpa/shikaku/ama/index.html)や[JARLのバンドプラン](https://www.jarl.org/Japanese/A_Shiryo/A-3_Band_Plan/A-3-0.htm)で確認できます。

## アンテナ・中継局・衛星を使うときの現実

### HFのアンテナは、どれくらい大きい？

アンテナの寸法は方式によって違いますが、目安として**半波長ダイポールの全長**を比べると次のようになります。

| バンド | 全長の概算 |
| --- | ---: |
| 3.5 MHz | 約40 m |
| 7 MHz | 約20 m |
| 14 MHz | 約10 m |
| 21 MHz | 約7 m |
| 28 MHz | 約5 m |

これは波長から見積もった寸法で、実際の切断長や設置寸法は給電方式・高さ・周囲の物体などで変わります。

7 MHz帯のダイポールをそのまま張る場所がなくても、HFを諦める必要はありません。限られた設置場所に合わせて、次のような方法を試せます。

- **HF用モービルホイップ：** 短いアンテナをベランダや移動先に設置する方法。適切な基台、カウンターポイズ（対向する電流経路）や接地条件、周囲の金属との関係が性能に影響する。
- **マグネチックループアンテナ：** 小さな輪を共振させる方式。狭い場所でも設置しやすい一方、調整が鋭敏で、同調用コンデンサなどに高い高周波電圧が生じるため、安全な構造が必要。
- **短縮ダイポールなどの自作：** 短縮コイルや導線の配置を工夫し、設置できる範囲で試作・調整する。アンテナを作り、測り、交信結果を比較すること自体もアマチュア無線の楽しみになる。
- **移動先で仮設する：** 自宅で設置できなくても、広い場所では長いワイヤーアンテナを展開できる。設置場所の許可と周囲の安全確保が必要。

短縮アンテナを使うと損失が増えやすく、特に周波数が低いほど設計や設置の難しさが増します。**SWRが低いことやアンテナチューナーで整合できたことは、効率よく電波が出ている証明ではありません。** 一方で、限られた設備でどこまで届くかを確かめるのも、立派な技術実験です。FT8やCWを使えば、音声では成立しにくい弱い信号で交信できる可能性もあります。

自宅のベランダや共用部では、建物の管理規約、落下・感電・高周波による危険、近隣への影響にも注意しましょう。

### 430 MHz帯のレピータは、近くにあるだけで十分？

**レピータ**は、山頂や建物などに設置された無線中継局です。直接届かない相手と交信する助けになります。430 MHz帯などでは、FMレピータに加え、D-STARによる音声通信やネットワーク接続も利用されています。

しかし、レピータの一覧表に掲載されていることだけでは、**現在稼働しているか、誰かが使っているか、手持ちの無線機でアクセスできるか**までは分かりません。送受信の周波数差やトーンなど、方式に合った設定も必要です。

- [JARL：全国レピータ局リスト](https://www.jarl.org/Japanese/A_Shiryo/A-1_Repeater/)
- [JARL：D-STARレピータの開設・変更・停波等の情報](https://www.jarl.com/d-star/osirase.htm)

また、**D-STAR・C4FM・DMRは、いずれもデジタル音声だからといって互換ではありません**。対応する方式の無線機・中継設備を確認しましょう。インターネットに接続されたレピータ・ノード経由の遠距離交信は便利ですが、相手まで電波だけで届いているわけではありません。

### 衛星通信は「近くに人がいない」を別の方法で解決する

アマチュア衛星やISSのアマチュア無線設備が利用できれば、地上の近隣局とは違う相手と交信できます。144・430 MHz帯のFM機で交信できる衛星もありますが、すべての衛星がFM音声に対応するわけではありません。

人工衛星は地平線の上に現れる時間が限られ、送信（アップリンク）と受信（ダウンリンク）で周波数が違うこともあります。**衛星の運用モード・通過時刻・送受信周波数を調べてから**設備を選びます。日本ではISSとの交信に144.490 MHzを使える場合のように、通常の衛星区分とは異なる用途限定の周波数使用条件もあります。[JARLの最新バンドプラン](https://www.jarl.org/Japanese/A_Shiryo/A-3_Band_Plan/A-3-0.htm)では、区分だけでなく注記まで確認できます。

## 日本の都市部と地方では、何が違う？

### 都市部：局が多そうでも、自宅から聞こえるとは限らない

人口の多い地域では交信相手やレピータの候補を探しやすい一方、マンションの鉄筋コンクリート、隣接する建物、ベランダの向きなどがVHF・UHFの電波を遮ることがあります。

HFでは、電源装置・電子機器・太陽光発電設備などが受信ノイズの原因になる場合があります。高性能な無線機を買っても、**受信アンテナの環境が悪ければ小さな信号は聞こえません**。

最初から大きな設備を考える前に、窓際・ベランダ・屋外・近所の開けた場所で受信状況がどのくらい変わるかを確かめると、改善の方向が見えます。

### 地方・山間部：電波が届くことと、利用者がいることは別

周辺の住宅が少なく、144・430 MHz帯のFMを何時間聞いても交信が始まらない地域があります。これは無線機の故障や、誰もアマチュア無線をしていないことの証拠ではありません。局がいても違う時間帯・方式・周波数で運用していたり、山の向こう側にいたりします。

山や谷に囲まれた場所では、**わずかな移動で受信状況が大きく変わる**こともあります。一方、見通しのよい高台からなら、比較的小さな出力でも遠くの局と交信できる可能性があります。

近所の声の交信が少なくても、HFによる全国との通信、FT8による国内外との通信、衛星通信、イベント・コンテストでの運用など、別の方法があります。

## 買ってから困らないための確認

### 「ハンディ機を買えば日本中の人と話せると思った」

一般的な144/430 MHz帯のFMハンディ機は、**近隣の相手との通信を得意とする設備**です。街中・谷間・室内などで、何十kmも離れた相手に必ず届くわけではありません。

全国と直接交信することを第一の目的にするなら、HF帯を使える無線機とアンテナの検討が必要です。既にハンディ機を持っているなら、近隣の運用イベント、レピータ、見通しのよい場所からの移動運用を試す道があります。

### 「周波数を回しても、誰も話していない」

声の通信を聞くには、**バンド・モード・周波数・時間帯**の組み合わせが合う必要があります。

FMの局が利用する周波数と、SSBやFT8の局が利用する周波数は違います。しかも、声でCQを出す代わりに短いデータだけを送っている局もいます。静かだったという一度の受信結果で、バンド全体の利用状況を判断するのは早計です。

まずは曜日と時刻を変えて聞き、近所のクラブやイベントの周波数も調べてみましょう。**聞こえないだけなら自局の受信条件、聞こえるのに交信できないなら送信側の条件**というように切り分けることも大切です。

### 「FT8や画像通信をやりたいのに、FM専用機だった」

FT8は主にパソコンとSSB対応の無線設備を組み合わせる方式で、FMの音声と同じようにダイヤルを合わせれば聞こえるものではありません。SSTVなどの画像通信にも、方式に応じた音声・データ入出力やソフトウェアが必要です。

なお、データ通信にはFM無線機を使う方式もあります。**「デジタルなら全部SSB」「データ通信なら全部同じ装置」というわけでもありません**。無線機の対応バンドとモード、PCとの接続方法を、やりたい通信方式から逆算することが重要です。

### 「HF機を買ったけれど、アンテナを張れなかった」

無線機が机に置けても、アンテナが設置できるとは限りません。特に低いHF帯では、屋外に十分な導線や空間を確保するのが難しいことがあります。

モービルホイップやマグネチックループを工夫して設置する、短縮アンテナを自作する、移動先で仮設する、といった道があります。**小さいアンテナでも無意味ではありませんが、損失・設置環境・受信ノイズを含めた検討が必要**です。まず受信してみて、FT8やCWなど弱信号に適した通信方式を試すこともできます。

## 無線機を買う前に、交信相手を探してみる

受信できる環境があれば、免許を取って送信する前でも、そのバンドにどんな電波があるか観察できます。購入前なら、体験運用やクラブ活動に参加し、実際の受信音や設備を見せてもらうのもよい方法です。

1. **聞きたい相手を決める。** 近隣の声、国内の声、海外、FT8、衛星では選ぶバンドもモードも違います。
2. **時間帯を変えて受信する。** HFでは昼夜で聞こえる地域が変わり、50 MHz帯ではEsなどで状況が急変します。VHF・UHFでは休日の移動局やイベントで初めて交信相手が聞こえることもあります。
3. **無線局・レピータが近くにあるか確認する。** レピータの一覧、地域クラブ、イベント告知を参考にします。ただし登録数は実際の交信の活発さを保証しません。
4. **データ通信の受信報告を見る。** [PSK Reporter](https://pskreporter.info/pskmap)では、FT8などのデータ信号がどの地域で受信されたかを調べられます。**受信報告は交信の成立記録ではなく、受信報告局の分布にも偏りがあります。**
5. **公開受信設備や交信イベントを活用する。** WebSDRなどの公開受信機でHF帯の様子を聞くこともできます。ただし、公開受信機の設置場所での受信状態は、自宅での受信状態を保証しません。

### 最初の無線機を選ぶためのチェック

購入前に次の項目が説明できれば、買い間違いを減らせます。

- **通信相手：** 近隣／国内／海外／衛星のどれか。
- **通信方式：** FM音声／SSB音声／CW／FT8／画像／デジタル音声などのどれか。
- **設置場所：** ハンディ運用／車載／自宅／移動先。アンテナをどこに置けるか。
- **聞こえる場所と時間：** その地域に相手がいるか、いつ活動しているか。
- **対応設備と資格：** 無線機・アンテナ・周辺装置と、自分の資格・無線局免許の条件が合っているか。

「最初に買う一台」に絶対の正解はありません。**運用したい地域と通信方式を先に決めれば、すでに持っている無線機が思うように使えない場合でも、アンテナ・場所・時間・モードを変えて再挑戦できます。**
