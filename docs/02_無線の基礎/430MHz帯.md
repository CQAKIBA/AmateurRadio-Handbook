# 430MHz帯（70cmバンド）

430MHz帯は、身近な場所での音声交信から、レピータを使った通信、アマチュア衛星、データ通信、アンテナの自作まで、幅広い活動ができるUHF帯です。日本では**430.000～440.000MHz**がアマチュア無線に割り当てられています。ハンディ機や車載機で利用しやすい一方、SSBやCWを使った遠距離交信、衛星の追跡、電子工作にも利用できます。

波長は中心付近の435MHzで約69cm、4分の1波長は約17cmです。7MHz帯のような日常的な電離層反射を前提とせず、**見通し・地形・アンテナの高さ**が交信できる範囲を大きく左右します。

| 基本項目 | 430MHz帯の特徴 |
| --- | --- |
| 通称 | **70cmバンド**。波長は約70cm |
| 日本での使用範囲 | **430.000～440.000MHz**。周波数ごとに通信方式・用途の使用区別がある |
| 身近な交信 | FMによる単信（シンプレックス）、レピータ、デジタル音声、近隣・移動局との交信 |
| 技術的な楽しみ | SSB・CW・FT8、パケット通信、衛星通信、EME（月面反射）、アンテナ・無線機の自作 |
| 注意点 | 障害物による減衰、反射・マルチパス、同軸ケーブルの損失、偏波、衛星・レピータ専用区間 |

## 伝搬特性

430MHz帯の交信距離は送信出力だけでは決まりません。同じハンディ機でも、屋内・市街地・谷間・高台・山頂では、相手に届く信号の強さが大きく変わります。

| 条件 | 電波の届き方 |
| --- | --- |
| **見通しのよい高台・山頂** | 遮る地形が少なく、数十km以上の相手とも交信できる場合がある。高所同士ではさらに遠くまで届くこともある |
| **市街地・屋内** | 建物や地形に遮られる一方、反射波によって直接見えない相手が聞こえることもある。少し移動するだけで受信強度が変化しやすい |
| **谷間・建物の陰** | 回折・反射で届く場合もあるが、低い出力よりもアンテナを置く位置が交信成否に効くことがある |
| **特別な伝搬条件** | 対流圏ダクト、航空機反射などで通常より遠方と交信できる場合がある。いつでも再現するわけではない |

電波には**偏波**（電界の振動方向）があります。地上のFM単信やレピータでは垂直偏波のアンテナが広く使われ、SSB・CWの弱信号通信では水平偏波のアンテナを用いることがあります。偏波が直交すると受信電力が大きく下がる場合があるため、相手の運用方式に合わせることも重要です。衛星通信では衛星の姿勢などによって偏波が変わります。

## 周波数の詳細解説

### 周波数表の読み方

次の表は**周波数の低い順**に並べた、日本の使用区別の概要です。「使用区別」「呼出・非常通信周波数」「コンテストでの使用周波数」「デジタル方式の慣行」は根拠が異なります。とくに単信・レピータ・衛星の区分は混同しないようにしてください。

| 周波数（MHz） | 主な使用区別と用途 | 留意点 |
| --- | --- | --- |
| **430.000～430.100** | **CW** | A1Aによる電信の区分。430.100MHzは非常通信周波数 |
| **430.100～430.700** | **狭帯域の全電波型式** | 主にSSB・CW・FT8など。JARLコンテストのAM/SSB区間は430.250～430.700MHz |
| **430.700～431.000** | **VoIP** | 無線とインターネット等を接続する通信の区分 |
| **431.000～431.400** | **広帯域データ** | パケット通信など。運用例として431.090MHzの9600bps APRSが知られる |
| **431.400～431.900** | **広帯域の電話・電信・画像** | FM音声などの区分 |
| **431.900～432.100** | **EME（月面反射）** | 月面反射通信に用途が限定された区分 |
| **432.100～434.000** | **広帯域の電話・電信・画像** | FM単信など。**433.000MHz**はFM呼出周波数、**433.300MHz**はデジタル呼出周波数 |
| **434.000～435.000** | **レピータ** | 中継局へのアップリンクに使用される区分。通常の単信とは異なる |
| **435.000～438.000** | **衛星** | アマチュア衛星通信に用途が限定された区分 |
| **438.000～439.000** | **全電波型式（実験・研究用）** | 運用可能な方式は技術基準・公衆網接続条件等にも従う |
| **439.000～440.000** | **レピータ** | 中継局からのダウンリンクに使用される区分 |

表の使用区別は[JARLの現行バンドプラン](https://www.jarl.org/Japanese/A_Shiryo/A-3_Band_Plan/bandplan20250717.pdf)を参照しています。狭帯域・広帯域は周波数帯全体の30kHz上限とは別の区分で、原則として占有周波数帯幅3kHzを境界とします（A3Eは例外）。個々の電波型式の条件は告示本文で確認する必要があります。

### 呼出周波数と非常通信周波数

FMの**433.000MHz**は相手を呼び出す周波数として知られています。相手と連絡が取れたら、使用できる区間で空いている周波数に移って交信を続けるのが基本です。**433.300MHz**はデジタル音声などの呼出周波数です。

また、430.100MHz、433.000MHz、433.300MHz、433.500MHzはJARLのバンドプランに非常通信周波数として示されています。非常時はこれらの周波数と、通信が占有する周辺の帯域を確保する配慮が求められます。[JARL東京都支部による非常通信周波数の案内](https://jarltokyo.com/blog/20251209_hokkaido_tohoku_earthquake)にも使用例があります。

### コンテスト・データ通信の運用周波数

JARLが案内するコンテスト使用周波数帯には、430.050～430.090MHz（CW）、430.250～430.700MHz（AM/SSB）、432.100～434.000MHz（FM）があります。これらは**コンテスト規約に従って運用するときの区分**であり、期間外に誰かの専用周波数となるわけではありません。[JARL：コンテスト使用周波数帯](https://www.jarl.org/Japanese/1_Tanoshimo/1-1_Contest/frequency.html)。

狭帯域データ通信では**430.510MHz付近のFT8**、広帯域データでは**431.090MHz付近の9600bps APRS**などが周波数案内に挙げられています。ただし、ソフトウェアの設定例・慣行と法令上の専用指定は異なります。[使用区別と周波数の整理例](https://michinoku-lab.com/radio/amateur-bandplan-202507/)も参照してください。

## 使われている通信方式

| 方式 | 430MHz帯での楽しみ方 |
| --- | --- |
| **FM音声** | ハンディ機・車載機・固定局の単信や移動運用。簡単な設備で始めやすい |
| **デジタル音声** | D-STAR、C4FMなどの対応機・対応方式を使う通信。異なる方式同士は原則としてそのまま通話できない |
| **レピータ** | 山上や建物に設置された中継局を介した通信。周波数・シフト・対応方式等の設定が必要 |
| **SSB・CW** | 弱い信号での遠距離交信やコンテスト。一般的なFM専用ハンディ機だけでは利用できない |
| **FT8などの狭帯域データ** | パソコンと対応無線設備で弱信号通信や伝搬観測を楽しめる |
| **AX.25・APRSなど** | パケット通信や位置・情報共有。必要な変調方式やデータ速度はシステムによって異なる |
| **アマチュア衛星** | 衛星の通過時刻・位置を予測し、アンテナ方向やドップラー偏移を追って通信する |
| **EME** | 月を反射体として使う通信。通常の近距離FM交信とは異なる設備・弱信号技術が必要 |

430MHz帯は**「FM専用のバンド」ではありません**。反対に、FM専用機ですべての430MHz帯の活動を受信・送信できるわけでもありません。

## 実際の使われ方と運用文化

### 近隣の単信と移動運用

身近な地域の局との会話は、430MHz帯を使い始める入口の一つです。受信できる相手は、地域、時間帯、周囲の建物、アンテナの設置環境によって異なります。登山や高台からの移動運用、コンテストの開催中には、普段は聞こえない局に出会うこともあります。

430MHz帯の手軽さは、アマチュア無線の目的である**個人的な興味、技術の研究や自己訓練**にも向いています。業務連絡を目的とした利用やコールサインを送出しない運用は、こうした活動と区別する必要があります。

### レピータ・デジタル音声

レピータは自局と相手の間を中継するので、直接波では届きにくい地域と交信できる場合があります。**受信周波数と送信周波数が異なる**構成が一般的で、単に433.000MHzで聞く・送信する操作とは違います。地域の稼働状況や対応するデジタル方式を確認しましょう。

- [JARL：全国レピータ局リスト](https://www.jarl.org/Japanese/A_Shiryo/A-1_Repeater/)
- [JARL：D-STARレピータ情報](https://www.jarl.com/d-star/osirase.htm)

### 衛星・弱信号通信

435～438MHzは衛星通信専用の区分です。周波数が合っていても、地上同士の単信に使ってよい区間ではありません。衛星の通信方式、送信・受信周波数、通過時刻、ドップラー偏移を調べて運用します。詳しくは[アマチュア衛星通信](../06_運用/アマチュア衛星通信.md)を参照してください。

SSBやCW、FT8などでは、FM音声と違う弱信号の世界を楽しめます。**相手局の偏波、アンテナの方向と高さ、受信帯域幅**を合わせることが大切です。

## 交信相手の見つけ方

**FM音声を聞いてみたいとき**は、433.000MHzの呼出周波数や、その周辺の単信に使える区間を受信してみましょう。呼出周波数だけ聞いて「誰もいない」と判断せず、時間帯を変え、地域の移動運用・コンテスト情報も調べると発見が増えます。

**デジタル音声やレピータを使いたいとき**は、対応方式と稼働中の中継局を先に確認します。**SSB・CW・FT8で交信したいとき**は、対応するオールモード機・設備を用意し、周波数だけでなく偏波や運用時間を合わせます。

初めての交信の流れは[基本運用 ― 音声で最初の交信をするまで](../06_運用/基本運用.md)も参考になります。

## 無線機・アンテナ・必要な機材

430MHz帯の4分の1波長アンテナは約17cmで、携帯・車載にも適した寸法です。一方、取り付け位置や近くの金属・人体の影響で性能は変わります。**アンテナが短く作れることと、どこでもよく飛ぶことは別**です。

- **ハンディ機：** FM・対応するデジタル音声を使った近距離運用に便利。建物の外や高所に移すだけでも受信が変化する。
- **車載機・固定機：** 外部アンテナの設置高さや給電線の取り回しを工夫できる。
- **オールモード機：** SSB・CW・FT8などに取り組む場合は、必要なモードへの対応を確認する。
- **指向性アンテナ：** 八木・宇田アンテナなどは、特定方向への通信、衛星追尾、弱信号通信に役立つ。

430MHz帯ではHFより同軸ケーブルの損失が問題になりやすくなります。無線機の出力を増やす前に、**アンテナの高さ・給電線の長さと損失・コネクタの状態**を確認すると、送受信の両方を改善できることがあります。

## よくある問題と解決方法

| 状況 | 確認したいこと |
| --- | --- |
| **ハンディ機で誰も聞こえない** | 周波数・モード・スケルチ設定を確認。場所・高さ・時間帯を変える。呼出周波数だけで判断しない |
| **聞こえるのにこちらの声が届かない** | 相手と送受信周波数が一致しているか、レピータ用シフト設定が残っていないか、アンテナと出力を確認 |
| **デジタル音声の音が出ない** | 対応方式や設定が一致しているか確認。D-STARとC4FMなどは互換モードではない |
| **近くでも受信が不安定** | 建物の反射・遮蔽、人体の影響、偏波の違い、アンテナや同軸の不具合を調べる |
| **衛星の信号が聞こえない** | 衛星の運用状況、通過位置、アンテナ方向、ドップラー偏移、受信モードを確認 |
| **新しいデータ方式を試したい** | 電波型式・使用区別に加え、占有周波数帯幅の許容値、免許条件を先に確認する |
