# 430MHz帯（70cmバンド）

430MHz帯は、小型のアンテナで近隣の局と交信でき、移動運用、レピータ、デジタル通信、人工衛星との交信、機器の製作や実験にも使われるUHF帯です。日本では**430～440MHz**がアマチュア業務に割り当てられています。

その一方で、日本の430MHz帯には、**電波型式ごとの一般的な占有周波数帯幅の許容値とは別に、430～440MHzを名指しした30kHz以下の上限**があります。海外の430MHz帯で使われる125kHz幅・250kHz幅のLoRaなどを、日本でもそのまま送信できるとは限りません。

| 基本項目 | 特徴 |
| --- | --- |
| 通称 | **70cmバンド**。中心付近の波長は約69cm |
| 日本での周波数範囲 | **430～440MHz** |
| 代表的な活動 | FM音声、レピータ、D-STARなどのデジタル音声、CW・SSB、データ通信、人工衛星・EME、アンテナ・通信機器の実験 |
| 伝搬 | 見通しや地形・建物、アンテナの位置が重要。高所からは遠方まで届くこともある |
| 特有の注意点 | **占有周波数帯幅30kHz以下の特則**。電波型式によっては、さらに小さな許容値が適用される |

使用できる周波数ごとの詳細な区分は、[JARLの現行バンドプラン](https://www.jarl.org/Japanese/A_Shiryo/A-3_Band_Plan/A-3-0.htm)を参照してください。「全電波型式」とされる周波数でも、**占有周波数帯幅の技術基準、無線局の免許条件、他局との共用上の制約がなくなるわけではありません**。ほかの周波数帯との比較は[日本のアマチュアバンドを選ぶ](japan-band-guide.md)を参照してください。

## 身近な運用と実験

430MHz帯は、ハンディ機や車載機で利用しやすく、アンテナを工夫する実験にも向いています。波長の4分の1は約17cmで、HF帯に比べると小さなアンテナを作りやすいのが特徴です。

音声交信だけでなく、パケット通信、デジタル音声、衛星通信、微弱信号の受信など、さまざまな実験が行われています。ただし、実際に交信相手が見つかるかどうかは地域・日時・モードによって異なります。**周波数帯が開放されていることと、任意の通信方式を自由な帯域幅で送信できることは別**です。

## 430MHz帯を名指しした30kHz制限

### 「バンドプラン」と「占有周波数帯幅」は別の規定

無線設備の発射電波については、**無線設備規則第6条・別表第二号**に基づく占有周波数帯幅の許容値が適用されます。アマチュア局については、別表第二号第54の規定を根拠とする**令和5年総務省告示第81号**が、電波型式ごとの許容値を定めています。

この告示の**注7**は、430～440MHz帯を明示して、表に定める値にかかわらず**30kHz以下**としています。例えば、表でF3Eの一般的な許容値が40kHzであっても、430MHz帯ではこの注記が適用されます。

一方、同じ告示には、電波型式によって430MHz帯を含む複数のバンドに**25kHz以下**など別の上限を定める注記もあります。したがって、「430MHz帯ならすべての通信方式で30kHzまで使える」という意味ではありません。

また、周波数帯ごとの「使用区別」を定める**令和5年総務省告示第80号**（いわゆる法令上のバンドプラン）と、設備が発射できる電波の占有周波数帯幅の許容値を定める第81号は、**目的が違う独立した規定**です。2023年の制度改正に対する意見募集でも、総務省はその違いを明確に説明しています。

### LoRaなどの広帯域データ通信への影響

LoRaはチャープ拡散スペクトラム方式を利用したデータ通信技術で、**公称帯域幅125kHz・250kHz**などの設定が知られています。これらの設定を430MHz帯でそのまま使用する場合、通常の30kHz以下という許容値を満たせません。なお、通信方式の設定値である「帯域幅」と、法令に基づいて評価する**占有周波数帯幅**は定義・測定上区別する必要があります。

2023年のアマチュア無線制度改正に際しては、**100kHzを超える広帯域LoRa**と従来の狭帯域通信とのすみ分けを求める意見が、総務省の意見募集に実際に提出されました。総務省は、占有周波数帯幅の許容値は他業務との共用のための技術基準であり、改正では既存のアマチュア局の運用状況に沿って規定したこと、利用状況等に応じて制度の見直しを行う考えであることを回答しています。

したがって、海外で430MHz帯用として紹介されるLoRaモジュールや実験例は、**周波数が合っているというだけでは日本のアマチュア局で送信できません**。実際の発射電波と免許条件に照らして判断する必要があります。

## 30kHzという数値の由来

430MHz帯だけを特に30kHz以下とする理由や、それが一般的な技術基準として**最初に制定された年月日は確定していません**。一方、この数値自体には古い使用例があります。

| 年月 | 確認できる出来事 | 読み取れること |
| --- | --- | --- |
| **1964年1月** | 日本で430～440MHz帯がアマチュア業務に開放 | バンド開放の時期。**30kHzの一律規制が始まった日付を示すものではない** |
| **1973年4月** | 日本でSSTVを初めて免許された24局について、430MHz帯のFM方式の占有周波数帯幅が**30kHz**と指定されたとの記録 | **個別免許の条件として30kHzという数値が使われた実例** |
| **2009年3月17日** | **平成21年総務省告示第125号**を制定。注3に430～440MHz帯の**30kHz以下**を明記 | 独立した告示に特則が存在したことを確認できる時点 |
| **2023年9月25日** | **令和5年総務省告示第81号**が施行。第125号を廃止し、430MHz帯の30kHz特則を**注7**に引き継いだ | 現在につながる条文の位置づけ |

1964年の430MHz帯開放当初には、アマチュアテレビ（ATV）への期待も記録されています。しかし、これは**その後のすべての時期に広い占有帯域幅が一般的に許されていた**ことの証明にはなりません。

また、**750kHz幅などの広帯域の個別免許**と、一般のアマチュア局に共通して適用される技術基準は区別して考える必要があります。個別の審査・決裁で免許が与えられた事例があっても、それを「ある時代には750kHzが一般に開放されていた」と読み替えることはできません。個別事例の許可範囲や根拠を確かめるには、当時の免許状・工事設計書などが重要です。

特に、**2009年の告示が「新規制定」であることと、30kHzという規制自体が2009年に初めて導入されたことは別問題**です。2009年より前の無線設備規則・別表第二号の規定や行政上の取扱いを確認しなければ、制度の起点を断定することはできません。

430MHz帯の古い免許記録、規則集、技術基準改正資料などをお持ちの方は、[GitHub Issues](https://github.com/CQAKIBA/AmateurRadio-Handbook/issues)から情報をお寄せください。特に**430MHz帯を名指しした30kHz制限の最初の制定根拠**や、広帯域の個別免許の条件を示す一次資料は、この制度の経緯を理解するうえで重要です。
