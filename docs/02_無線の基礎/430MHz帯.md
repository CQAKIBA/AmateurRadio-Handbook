# 430MHz帯（70cmバンド）

430MHz帯は、ハンディ機や車載機による近距離交信から、レピータ、デジタル音声、データ通信、人工衛星との交信まで楽しめるUHF帯です。日本では**430～440MHz**がアマチュア無線に割り当てられています。アンテナを比較的小さくできる一方、建物・地形・設置場所によって通信できる範囲が大きく変わります。

| 基本項目 | 430MHz帯の特徴 |
| --- | --- |
| 通称 | **70cmバンド**。波長は約70cm |
| 日本での周波数範囲 | **430.000～440.000MHz** |
| 主な使い方 | FM・SSB・CW、デジタル音声、レピータ、衛星通信、データ通信、アンテナや無線機の実験 |
| 伝搬 | 基本的には見通し・回折・反射が重要。高所や異常伝搬を利用した遠距離交信も行われる |
| 制度上の特徴 | **430～440MHz帯を名指しする、占有周波数帯幅30kHz以下の特別な上限**がある |

日本の430MHz帯は、1964年1月に開放されました。[JARLの歴史年表](https://www.jarl.org/Japanese/A_Shiryo/A-6_History/History-02.htm)にも、その記録が残っています。

## 使用区別と実際の運用

430～440MHzの全域を、任意の通信方式で自由に使えるわけではありません。周波数ごとにCW・狭帯域通信・電話・データ通信・衛星・レピータなどの**使用区別**があります。例えば、430MHz帯の低い側ではCWや狭帯域通信、432～434MHz付近ではFM電話、435～438MHzには衛星通信の区間、434～435MHzおよび439～440MHzにはレピータに関係する区間が設けられています。

また、SSB、FM、デジタル音声、データ通信は、受信する方式や通信相手が一致しなければ交信できません。レピータ経由では送受信周波数やアクセス条件も確認します。アンテナの設置高度や周囲の建物によっては、数km以内の局が聞こえない一方、見通しのよい山頂から遠方と交信できる場合もあります。

最新の区分と注記は、[JARLのアマチュアバンドプラン（2025年7月17日施行）](https://www.jarl.org/Japanese/A_Shiryo/A-3_Band_Plan/A-3-0.htm)で確認できます。使用区別とは別に、以下の**無線設備の技術基準**も適用されます。

## 430MHz帯に固有の占有周波数帯幅30kHz制限

2023年9月25日施行の**令和5年総務省告示第81号**「アマチュア局の無線設備の占有周波数帯幅の許容値」には、次の規定があります。

> **注7**　430MHzから440MHzまでの周波数の電波を使用する場合の占有周波数帯幅の許容値は、占有周波数帯幅の許容値の欄に規定する値にかかわらず、**30kHz以下**とする。

これは、周波数ごとの「どの電波型式を使えるか」を定める**使用区別（バンドプラン）とは別の、無線設備規則に基づく占有周波数帯幅の制限**です。使用区別に「全電波型式」と書かれている区間でも、この30kHzという上限が無条件になくなるわけではありません。

また、**30kHz以下ならどの電波型式でもよいという意味でもありません**。電波型式ごとに表で定められた許容値が30kHzより小さい場合や、使用区別・免許条件などによる制約がある場合には、そちらにも適合させる必要があります。

この告示は、2009年の平成21年総務省告示第125号を廃止して制定されました。[総務省の制度改正に関する命令・告示一覧（e-Gov意見公募資料）](https://public-comment.e-gov.go.jp/pcm/download?seqNo=0000250744)に、新旧告示の関係と2023年9月25日の施行日が記されています。

### LoRaなどの広帯域デジタル通信への影響

海外のアマチュア無線でも使われる**LoRa**は、周波数を時間とともに変化させるチャープ拡散変調です。一般的な設定には**BW 125kHz、250kHz、500kHz**があり、これらは430MHz帯の通常の30kHzという上限より大幅に広いものです。このため、**海外の430MHz帯で使われている設定を、そのまま日本の430MHz帯で送信できるとは限りません**。

一方、LoRaという方式自体が一律に禁止されているわけではありません。例えばSemtech製SX1276／SX1278などには**7.8、10.4、15.6、20.8kHz**等の狭帯域設定もあります。ただし、ICの「BW」設定は変調器の公称帯域であり、法令上の**占有周波数帯幅の実測値そのものを保証する数字ではありません**。実際の送信スペクトラム、電波型式、使用区別、免許条件の確認が必要です。

参考：[Semtech：LoRa Connect製品群・設定可能なBW](https://www.semtech.com/products/wireless-rf/lora-connect)

## 30kHzという値は、いつから使われていたのか

現在の一律の注記がいつ成立したかを考えるには、**当時の免許条件、周波数使用区別、無線設備の占有周波数帯幅の技術基準**を区別する必要があります。同じ30kHzという数値が現れても、規定の適用範囲まで一致するとは限りません。

| 年 | 確認できる出来事 | 30kHz制限との関係 |
| --- | --- | --- |
| **1964年1月** | 日本で430～440MHz帯がアマチュア無線に開放 | 開放時の占有帯域幅制限は、この事実だけでは分からない |
| **1968年** | 富士山頂から430MHz帯のアマチュアテレビ映像を送信した記録がある | かつて広帯域の映像伝送実験が行われていたことを示す |
| **1973年4月** | 初期のSSTV免許で、430MHz帯のFM方式に**30kHz**が指定された | 個別の免許条件として同じ数値を確認できる |
| **2004年1月** | 平成15年総務省告示第508号の使用区別に、430～440MHz帯を**30kHz以下**とする注記が存在 | **2009年より前にも明文規定があった**。ただし特定の区分・電波型式に付随する条件 |
| **2009年3月17日** | 平成21年総務省告示第125号が新規制定され、**注3**に430～440MHz帯の30kHz上限が記載された | 占有周波数帯幅を定める独立した告示として確認できる |
| **2022年6月22日** | 430MHz帯のLoRa-APRSについて、**750kHzの占有周波数帯幅を個別指定**された免許の実例 | 旧告示の例外的な個別指定規定が実際に使われた |
| **2023年9月25日** | 令和5年総務省告示第81号が施行され、旧第125号を廃止 | **注7**に430MHz帯の30kHz上限を引き継ぐ。一方、旧告示にあった個別指定の規定は引き継がれなかった |

2004年の規定は、[当時の使用区別の変遷を収録した資料](https://jj1wtl.seesaa.net/article/501553392.html)で確認できます。1973年のSSTV免許は[アイコムによるJA3AER荒川泰蔵氏の記録](https://www.icom.co.jp/personal/beacon/ham_life/ja3aer/4883/)に、1968年のアマチュアテレビ実験は[同社のJA1BC作間澄久氏の記録](https://www.icom.co.jp/personal/beacon/ham_life/ja1bc/4933/)に記載されています。2009年告示の本文は[平成21年総務省告示第125号](https://motobayashi.net/kokuji/20090317-125.html)、改廃の経緯は[占有周波数帯幅に関する告示の変遷](https://motobayashi.net/history/kokuji/width.html)で確認できます。

### 2022年のLoRa-APRS個別指定という実例

**JA5FP 相田幸久氏**は『[LoRa APRSの製作と運用](https://www.catv296.ne.jp/~ja5fp/lora-aprs.pdf)』で、2022年6月22日付のアマチュア局免許について報告しています。旧告示第125号の**第3項**は、通常の許容値を満たすことが困難な設備について、占有周波数帯幅を**別に指定できる**と定めていました。同氏はこの規定に基づき、**750kHzの個別指定**を受けたと説明しています。資料には、LoRa-APRSによる438.575MHz付近の通信実験や使用機材も掲載されています。

これは**430MHz帯で広帯域LoRaの送信が個別に認められた実例**であって、ほかの局にも一般的に750kHzが認められたという意味ではありません。

2023年の告示第81号では旧告示にあった同様の個別指定条項がなくなっています。**過去の個別指定免許が現在どう取り扱われるか、現制度で同種の実験をどのように審査・許可できるかについては、この改正履歴だけでは結論を出せません。**

## 技術実験と周波数の使い方を考える

430MHz帯は、比較的小型のアンテナや無線機で自作・改造・データ通信の実験に取り組める周波数帯です。一方、実験したい方式が世界で一般的であっても、国内の使用区別や占有周波数帯幅の条件に合わないことがあります。

特に興味深いのは、**1960年代のアマチュアテレビ実験、1970年代のSSTV、2004年以前から確認できる30kHzの条件、2022年のLoRa個別指定、そして2023年の告示再編**が、同じ430MHz帯の歴史に並んでいることです。

30kHzという値が**最初に導入された年月日と、その際の技術的・行政的な理由**は、まだ確定していません。古い無線設備規則・告示の原文、免許指定の記録、当時の審査資料などをお持ちの方は、[GitHub Issues](https://github.com/CQAKIBA/AmateurRadio-Handbook/issues)で資料や情報を共有してください。

現在の送信可否を判断する際には、過去の運用例をそのまま適用せず、最新の規則、使用区別、各局の免許条件を確認する必要があります。
